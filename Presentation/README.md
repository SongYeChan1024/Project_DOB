# 층계참 식당 기획·발표 사이트

[발표 사이트 열기](https://songyechan1024.github.io/Project_DOB/)

첫 화면은 게임의 타이틀입니다. ‘다음’을 누르면 네 메뉴를 차례로 소개합니다. 타이틀에서 메뉴 이름을 눌러 해당 장면으로 건너갈 수도 있습니다. ‘새로 시작’을 따라가면 튜토리얼에서 만난 손님을 자리에 안내하고, 음식을 대접하고, 방명록을 읽은 뒤 마감을 확인합니다. 다음 날 아침에는 영업 준비로 가거나 별도 시장 테스트 화면을 둘러볼 수 있습니다.

비교 장면에서는 왼쪽의 기획 시안과 오른쪽의 실제 플레이 캡처를 대조할 수 있습니다. 휴대폰에서는 두 탭을 전환합니다. 어느 쪽이든 이미지를 누르면 확대됩니다. 각 이미지 아래에 촬영한 상태나 시안의 용도를 적었습니다. [장면 이미지 출처](comparisons/README.md)

## 로컬에서 열기

Node.js가 설치된 PC에서 저장소 루트를 열고 다음 명령을 실행합니다.

```sh
node Presentation/build.mjs
```

생성된 `Presentation/dist/index.html`을 브라우저로 엽니다. 오프라인 발표를 위해 다른 PC로 옮길 때에는 `dist` 폴더 전체를 복사합니다. ←·→ 키나 화면의 이동 버튼으로 장을 바꾸고, 휴대폰에서는 좌우로 밀어 이동합니다. 하단의 장 번호를 누르면 목록에서 원하는 장면으로 바로 갈 수 있습니다. **흐름도 자료실**에서는 다섯 가지 게임 규칙을 자세히 살펴볼 수 있습니다.

## 자료 갱신과 공개

발표 순서·메뉴 분기·설명은 [features.js](features.js), 장면별 시안·캡처·캡션은 [comparisons.js](comparisons.js)에서 편집합니다. 같은 장면의 두 그림을 비교하거나 단일 그림을 연결할 수 있습니다. 빌드는 등록한 파일을 자동으로 복사합니다. 배경 네 장은 Unity의 [Loading 스프라이트 폴더](../Assets/_DOB/07.UI/Sprites/Loading/)에서 가져옵니다. 다섯 흐름도의 설명은 [content.js](content.js), 그림은 [기획 원본 폴더](../Docs/기획/플레이/Flowcharts/)에 있습니다.

[배포 워크플로](../.github/workflows/presentation-pages.yml)는 관련 변경이 `main`에 병합되면 사이트를 빌드하고 `Presentation/dist`를 GitHub Pages에 게시합니다.
