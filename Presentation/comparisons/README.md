# 발표 장면의 이미지 출처

| 발표 자료 | 촬영·제작 기준 |
| --- | --- |
| 식당·주방·다음 아침의 초기 원화 | 팀이 2026년 10월 26일에 만든 공간·행동 참고도다. [원화와 제작 기록](../../Docs/References/3D/README.md) |
| 응대·퇴장의 발표용 기획 시안 | 2026년 11월 24일에 원고에 맞춰 그렸다. 클릭한 말의 밑줄과 수첩, 방명록과 표정 말풍선을 설명한다. [그림과 제작 기록](before/README.md) |
| 실제 플레이 | Windows 플레이어에서 타이틀을 열고 한 손님을 맞아 다음 날 다시 영업하기까지 촬영했다. 각 장면의 입력, 게임 버전, 캡처 원본을 기록했다. [촬영 기록](after/SOURCES.md) |
| 시장 UI | 팀원이 준비 화면을 독립 Unity 테스트 씬에서 열어 촬영한 `1_Market` 이미지다. 시험용 재고와 금화가 적용돼 있다. [프런트엔드 PR #20](https://github.com/SongYeChan1024/Project_DOB/pull/20) · [첨부 원본](https://github.com/user-attachments/assets/0b25bc3a-7db6-4c4c-82d7-115a36b4ea54) |

장면 순서와 메뉴 분기는 [발표 원고](../features.js)에, 화면별 원본 경로와 캡션은 [발표 이미지 목록](../comparisons.js)에 있다.
