# 첫 영업 실제 플레이 캡처

## 아라의 첫 방문

게임 소스 `7a33aacc31fc59a5fc1fe6890d143ad0d5b4d68e`의 Windows x64 플레이어에서 2026년 11월 24일 촬영했다. Unity 6000.4.0f1, Direct3D 11, 1600 × 900 PNG 원본이다. 별도 저장 폴더가 빈 상태에서 타이틀의 **새로 시작**을 눌렀다. 1일차 첫 손님은 무작위로 뽑힌 **드워프 전사 아라**였다. [게임 소스](https://github.com/SongYeChan1024/Project_DOB/tree/7a33aacc31fc59a5fc1fe6890d143ad0d5b4d68e)

영업 진입 순서는 `Title → Loading → Basement + BasementRestaurant + BasementUI`였다. 촬영 도구가 WASD·E와 게임 EventSystem의 화면 좌표 클릭을 보내고 실제 렌더링 프레임을 저장했다. 첫 응대부터 방명록·마감까지 기록된 아라의 방문 ID는 `824323308f3a474c8ff8f62032e3f877`이다. [씬 구성](https://github.com/SongYeChan1024/Project_DOB/blob/7a33aacc31fc59a5fc1fe6890d143ad0d5b4d68e/Assets/_DOB/02.Scripts/Manager/BasementComposition.cs) · [방문 생성](https://github.com/SongYeChan1024/Project_DOB/blob/7a33aacc31fc59a5fc1fe6890d143ad0d5b4d68e/Assets/_DOB/02.Scripts/Manager/GuestManager.cs)

| [입구](restaurant.png) | 손님 앞까지 걸으면 E로 맞이하라는 안내가 뜬다. 왼쪽 입구, 1~3번 좌석, 오른쪽 주방과 던전 계단이 보인다. |
| [첫 응대](guest.png) | E를 누르면 아라가 “내가 지나면 바닥돌이 덜컥하곤 해.”라고 말한다. 초상화 영역에는 ‘그림 대기’가 표시된다. |
| [대사 단서](guest-generated.png) | ‘바닥돌이 덜컥’을 누르면 그 표현에 밑줄이 생긴다. 수첩은 ‘함정 1’, 대사 단서 사전은 ‘함정 +1’을 표시한다. 닫고 같은 손님에게 E를 눌러 재열기한 뒤 수첩을 펼친 프레임도 이 PNG와 바이트 단위로 일치했다. |
| [관찰 단서](notebook-generated.png) | 같은 방문의 초상화 단서를 누르면 ‘작은 키와 수염 · 묵직한 발걸음’이 관찰 단서로 추가된다. 대사와 관찰은 같은 원인을 가리켜 사전에는 두 기록이 보이고 위험 칸은 ‘함정 1’을 유지한다. |
| [착석](seating.png) | ‘따라오세요’를 누르고 1번 자리까지 걸어 E를 눌렀다. 아라가 앉고 오른쪽 주방에서 아라의 구운 빵을 준비하라는 안내가 뜬다. |
| [재료 확인](recipe.png) | 주방에서 E를 누르면 ‘아라의 구운 빵’과 밀가루 2개·마늘 1개, 마늘 재고 2개, 조리 6초가 보인다. |
| [조리](kitchen.png) | ‘조리 시작’을 누르면 재료 창이 닫히고 화면 상단에 빵을 굽는 중이라는 문구와 6초가 표시된다. |
| [접시 들기](carrying.png) | 빵이 완성된 뒤 E로 접시를 들었다. 아라의 자리로 돌아가라는 안내가 보인다. |
| [서빙](serving.png) | 1번 자리에서 E를 누르면 영수증에 세 줄이 보인다. 아라의 맛 소감 “고소한 빵에 마늘 향이 나네.”, 각오 “이 정도면 끝까지 버틸 수 있겠어.”, 서빙 +9금화·보유 59금화·남은 마늘 1개다. |
| [던전으로 출발](departure.png) | 서빙 후 아라가 던전 계단 쪽으로 걸어간다. 화면 상단에 손님이 던전으로 내려가는 중이라는 문구가 보인다. |
| [방명록](guestbook.png) | 추가 입력 없이 기다리면 ‘아라 “고소한 빵에 마늘 향이 나네.”’가 적힌 방명록이 열린다. 이 프레임에는 던전으로 떠났다는 안내도 보인다. |
| [마감](settlement.png) | 방명록의 ‘닫기’를 눌렀다. 손님이 떠난 식당에 영수증이 남고 오른쪽 아래 ‘마감 확인’이 활성화돼 있다. |
| [2일차 아침](morning.png) | ‘마감 확인’을 누르면 2일차 아침 카드와 ‘보고 확인’ 버튼이 열린다. 귀환 보고 본문은 ‘준비 중’이며 보유 금화 **59**, 마늘 **1개**가 표시된다. |
| [2일차 준비](preparation.png) | ‘보고 확인’을 누르면 2일차 영업 준비 카드와 ‘영업 시작’ 버튼이 뜬다. 보유 금화 59·마늘 1개를 확인했다. |
| [2일차 영업](next-day.png) | ‘영업 시작’을 누르면 카드가 닫히고 다음 방문의 손님에게 다가가라는 안내가 뜬다. |
