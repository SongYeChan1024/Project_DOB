# 3D 제작 참고도

작성자: 송예찬 · 작성일: 2026.10.26

상태: 💡 과거 제작 참고도. 거리·크기·모델·카메라·효과 범위는 검토값이다. 이미지 안의 번호·화살표·상태 흐름은 구현 설명이며, 게임 화면에 표시할 UI가 아니다.

현재 제작은 [최신 결정](../../기획/CurrentDecisions.md)을 따른다. E 응대의 2D 초상·대사·알려진 위험·효과 비교·귀환 원인은 첫 루프에 포함한다. 대화·수첩·재료 선택 중 영업·입장·이동은 멈추지만 조리는 진행한다. 주인공은 카엘(A안)이며, 이 문서의 과거 이미지가 최신 규칙과 다르면 본문 명세가 우선한다.

## 이미지와 명세의 연결

- 번호가 붙은 대상마다 필요한 3D 오브젝트, 상호작용 위치, 상태 변화, 연결 이벤트를 확인한다. 프리팹 이름과 씬 담당은 팀 규칙에 따라 별도로 결정한다.
- 조리 그림의 냄비·프라이팬·오븐은 💡 도구 후보다. 종류별 레시피 대응, 재료 차감·취소·완성품 처리 시점은 🔴 별도 명세가 필요하다.
- 귀환 그림의 건강한 모습과 붕대 모습은 서로 다른 결과의 예시다. 전리품·기록은 확정 보고를 기준으로 한 번만 반영하는 안을 검토한다.
- 손님 이름은 [과객 이름 생성 명세](../../기획/GuestNames.md)를 따른다. 이름은 무작위로 부여·저장하고 컨디션은 표정·자세·대사 또는 별도 태그로 표현한다. 태그 UI는 후순위다.
- 인물은 임시 형태다. [스토리 B안](../../기획/StoryBTriggers.md)의 주인공 외형이나 고립 원인을 확정한 그림이 아니다.
