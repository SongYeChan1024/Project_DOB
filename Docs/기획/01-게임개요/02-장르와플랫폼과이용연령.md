## 장르

정보 추리 + 식당 경영(타이쿤) / 3D 쿼터뷰 / 싱글 플레이

플레이의 한 사이클은 손님 한 명을 읽고 처방해 보내는 것이다.
단서를 모으는 추리, 재료와 금화를 굴리는 경영, 단골과 쌓아 가는 관계가 하루 단위로 맞물린다.
장르 포지션과 참고 게임은 [레퍼런스와 장르 포지션](../02-타겟사용자/02-레퍼런스와장르포지션.md)에 있다.

## 플랫폼과 개발 환경

| 항목 | 기준 |
| --- | --- |
| 중점 플랫폼 | PC Windows 빌드 |
| 개발·테스트 환경 | Unity Editor 6000.4.0f1, URP, PC Standalone |
| 조작 기기 | 키보드 + 마우스 ([화면 순서와 조작](../06-인터페이스/01-화면순서와조작.md)) |
| 주요 3D 공간 | 식당 |

4인 팀이 작업 범위에 집중할 수 있도록 PC 단일 플랫폼으로 범위를 고정한다.
🔴 개발 착수일과 기간은 실제 제작 검증 후 다시 정한다.

## 이용 연령과 표현 강도

12세 이상 이용가를 목표로 한다.
부상은 붕대와 땀방울, 지친 표정 같은 가벼운 연출로만 보여 주고 유혈이나 사망 표현은 넣지 않는다.
주 타깃 연령(25~39세)은 [주요 타깃과 사용자 니즈](../02-타겟사용자/01-주요타깃과사용자니즈.md)를 따른다.
