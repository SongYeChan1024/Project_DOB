## 개인 취약점 상세

독 — 기침·창백한 얼굴 / 열 — 화상 자국 / 냉기 — 떨림·목도리 / 어둠 — 찡그린 눈 / 함정 — 절뚝거림.

축마다 그림 레이어 1개, 총 5개이며 그림·대사·아이콘으로 함께 알린다.

체력은 기존 피곤함 컨디션이 맡으므로 개인 취약점 대상에서 제외한다.

guestId에 고정하여 재방문·단골 전환·불러오기 뒤에도 유지한다. 확인한 취약점은 수첩 단골 탭에 기록한다.

종족·컨디션·개인 취약점을 먼저 합산하고 직업 보정을 적용한다. 돌발·활력 여유 보험 뒤 최종 부족 합을 계산하는 기존 순서는 유지한다.

personalWeaknessChance: float, 0.3(시험값) / personalWeaknessAxis: 위험 축 enum 또는 없음 / 취약점별 일러스트 레이어 정의.

## 튜토리얼과 확인 기준

> 아래 「첫날 안내 3명」은 0일차 연습안에 해당한다([F14](../../개발/FeatureManagerMap.md#저장과-후속-제작--튜토리얼-사운드-스토리)). 둘째 날 취약점 소개 시점은 0일차 신설과 함께 다시 검토한다.

첫날 안내 3명은 취약점 없이 진행한다. 둘째 날 처음 만나는 손님에게 그림과 대사로 취약점을 한 번 소개한다.

무작위 첫 손님 응대 → 두 손님 병행 응대 → 다음 아침 보고·양피지 독백의 흐름을 따른다. 목표 길이는 5~8분이다.

응대·재료 선택·수첩의 자동 조리는 진행한다. T08·T10에서 읽는 동안에도 완성될 수 있다고 안내한다.

잔여 4초에 응대 10초: 응대 중 완성, 닫으면 접시 ready. 일시 정지 메뉴·아침 보고·회상에서는 조리도 멈춘다.

첫 양피지 독백과 그림은 카엘(A안) 기준이다. 대성공 예: 「그릇이 비었다. 돌아올 힘까지 담겼던 모양이다.」
