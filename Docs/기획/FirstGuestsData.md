## 2. 손님별 데이터와 판정

계산 순서는 노션 5장: 층 기본 위험 + 종족 약점 → 직업 보정 → 0 미만은 0 → 처방 효과와 비교, 부족 합으로 등급.

### 손님 1 — 안내 (확정 기준, tutorial-spec 그대로)

| 항목 | 값 |
| --- | --- |
| guestId | `tutorial_guest_01` |
| 이름 | 💡 하루 (`name_001`) |
| 종족 · 직업 | 인간 · 마법사 |
| 위험 계산 | 독 1 · 체력 1 · 열 0 → 인간 보정 없음 → 마법사 열 −1 (0 아래로 내려가지 않음) |
| **최종 위험** | **독 1 · 체력 1** |
| 정답 | 구운 빵(밀가루 2) + 마늘 → 해독 1 · 활력 1 · 감각 1 |
| 부족 | 0 → **대성공**, 전리품 3 |
| 마늘 재고 | 2 → 1 |

### 손님 2 — 병행 연습 (하플링 사제 · 2026-11-08 송예찬 선택)

| 항목 | 값 |
| --- | --- |
| guestId | `tutorial_guest_02` |
| 이름 | 💡 보리 (`name_002`) |
| 종족 · 직업 | 하플링 · 사제 |
| 위험 계산 | 독 1 · 체력 1 → 하플링 체력 +1 → 사제 독 −1 |
| **최종 위험** | **체력 2** (독 0) |
| 정답 | 고기 구이(고기 2) → 활력 3. 부족 0 → **대성공** |
| 다른 답 | 구운 빵 + 소금 → 활력 2. 부족 0 → 대성공 (소금 사용) |
| 흔한 실수 | 구운 빵만 → 활력 1. 부족 1 → 성공 |
| 마늘 실수 (E1) | 구운 빵 + 마늘 → 활력 1. 부족 1 → 성공. 마늘이 0이 되어 손님 3에 영향 |
| 마늘 재고 | 정답이면 1 그대로 |

**왜 하플링인가:** tutorial-spec의 원래 안(인간 사제)은 최종 위험이 체력 1이라 구운 빵만으로도 대성공이다.
그러면 카드의 "고기 구이로 대비"가 꼭 필요한 선택이 아니다. 하플링이면 작은 키(외형)가 체력 +1을 뜻해서, 활력이 큰 고기 구이를 고를 이유가 생긴다.
새 위험 축은 늘지 않아 첫날은 여전히 독 · 체력 두 축만 다룬다.

### 손님 3 — 병행 연습 (tutorial-spec 그대로: 인간 전사)

| 항목 | 값 |
| --- | --- |
| guestId | `tutorial_guest_03` |
| 이름 | 💡 솔 (`name_003`) |
| 종족 · 직업 | 인간 · 전사 |
| 위험 계산 | 독 1 · 체력 1 → 인간 보정 없음 → 전사 체력 −1 |
| **최종 위험** | **독 1** (체력 0) |
| 정답 | 아무 요리 + 마늘 → 해독 1. 예: 구운 빵 + 마늘. 부족 0 → **대성공** |
| 흔한 실수 | 마늘 없이 → 해독 0. 부족 1 → 성공 |
| 마늘 재고 | 1 → 0 |

마늘이 해독을 낼 수 있는 유일한 수단이다. 첫날에는 해독이 있는 레시피(1층 재료 필요)가 아직 없다.

| **선택** | **하플링 사제 · 체력 2** | **인간 전사 · 독 1** | 종족 단서 1개만 추가, 축은 두 개 유지 |
| 종족 강조 | 하플링 사제 · 체력 2 | 드워프 전사 · 독 1 · 함정 1 | 구운 빵의 감각이 함정을 막는 걸 보여 줌. 첫날 축이 셋으로 늘어남 |
