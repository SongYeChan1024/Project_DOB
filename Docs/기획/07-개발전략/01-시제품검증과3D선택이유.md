## 웹 프로토타입에서 확인한 것 (2026-10 웹 시제품 기준)

아래는 당시 웹 시제품이 실제로 돌린 범위다. 현재 Unity 제작 범위(1층 본영업 루프 우선, 1~2층 검증, 5층·22레시피는 확장 목표)와는 다르다([제작 범위와 우선순위](02-제작범위와우선순위.md)).

| 확인한 것 | 내용 |
| --- | --- |
| 판정과 데이터 | 여섯 축 판정, 층 5개, 레시피 22개, 양념 6개, 직업 6개가 하나의 하루 루프로 돈다 |
| 추리의 재료 | 대사에서 직접 찾은 표현, 목적지, 직업, 컨디션, 오늘의 소식, 수첩 세 탭 |
| 성장의 연쇄 | 전리품 → 새 재료 → 새 레시피 → 다음 층 개방 |
| 관계 | 단골([단골] 태그), 호감, 조합 사연, 약속 재료, 부상 휴식 |

웹 시제품의 당시 구현값(2.4초 조리·화구 1개·유한 기본 재료·호감 0~12 등)은 [웹 시제품 기록](웹시제품기록/)에 보관한다. 현행 기준이 아니다.

| 아직 확인하지 못한 것 | Unity 버전에서 검증할 질문 |
| --- | --- |
| 자리 처방 | 자리 효과가 판정을 너무 쉽게 만드는가 |
| 실시간 영업 | 손님이 겹쳐 들어올 때 대화·조리·서빙 순서가 재미있는 바쁨이 되는가 |
| 3D 단서 | 직업 장비와 컨디션 몸짓이 대사만큼 읽히는가 |
| 플레이 시간 | 하루와 1막의 길이 (🔴 측정 필요) |

## 왜 3D인가

재설계안 「3D여야 하는 이유」의 두 가지(요리를 한다, 손님에게 맞는 자리를 골라 배치한다)를 설계로 옮긴다.

| 이유 | 설계 |
| --- | --- |
| 자리가 처방이다 | 자리의 효과는 난로·창·화분·칸막이처럼 공간에 놓인 사물에서 나온다. 쿼터뷰로 한눈에 보이고, 자리를 늘릴 때 무엇을 놓을지가 처방 수단을 고르는 일이 된다. |
| 몸으로 단서를 읽는다 | 쿼터뷰 운영은 3D 동선으로, 응대는 2D 초상·직업 장비·컨디션·단서 레이어와 대사로 전달한다. |
| 동선이 곧 시간이다 | 입구·자리·카운터를 직접 걸어 다닌다. 누구에게 먼저 가고 무엇을 먼저 나를지가 경영 판단이 된다. |
| 던전이 식당 바로 아래에 있다 | 계단을 내려가는 손님, 붕대를 감고 돌아온 단골이 같은 공간에서 보인다. |

🟡 몸짓 단서는 애니메이션 비용이 든다. 초기 구현에서는 머리 위 작은 효과(땀방울, 김)를 먼저 검토하고, 애니메이션 범위는 제작 여건을 보고 정한다.

## 3D라서 가능한 아이디어 (💡 제안 단계)

| 아이디어 | 내용 | 쓰는 곳 |
| --- | --- | --- |
| 손님 외형을 단서로 | E 응대 구도에서 종족·직업 기본 2D 초상과 상태 레이어를 관찰한다. 개인 취약점 5축은 그림·대사·아이콘으로 함께 알리고 체력 피로와 구분한다. 종족 약점과 개인 취약점이 같은 축이면 합산한다(예: 수인 + 기침 → 독 +2). | [단서 추리와 수첩](../04-핵심플레이/04-단서추리와수첩.md) |
| 자리 소품 효과를 공간으로 | 첫 완성본은 고정 소품과 연결 좌석의 효과를 구매 전에 보여 준다. 위치·방향·인접 거리·복수 소품 중첩은 확장 명세로 남긴다. | [자리 안내와 효과](../04-핵심플레이/05-자리안내와효과.md) |
| 층계참 구조 보여 주기 | 손님은 위층 계단으로 들어오고, 식사 뒤 던전 계단으로 내려간다. 다음 날 결과에 따라 그을리거나 멀쩡한 모습으로 올라온다. 계단 아래에서 올라오는 빛 색으로 오늘의 이변을 예고한다(3층 용암 균열은 붉은빛, 2층 곰팡이 동굴은 푸른 포자 안개). | [귀환 보고와 재방문](../04-핵심플레이/07-귀환보고와재방문.md) |
| 단골이 남긴 물건으로 식당 꾸미기 | 단골 사연에서 받은 문장·구급함·광석·열쇠·지도를 식당에 실제로 놓는다. 식당이 손님들의 이야기로 채워지는 게 눈에 보인다. 데모 이후 스토리 범위다. | [단골 사연 대사 원고](../03-세계관과스토리/단골사연대사원고.md) |

🟡 응대용 초상·표정·상태 레이어의 호환성과 제작량은 아트 담당이 검토한다.
