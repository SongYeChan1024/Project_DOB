역할 배정의 기준은 저장소 README 4장 「담당과 책임 분리」와 팀 노션 「팀 구성 · 협업 규칙」이다. 이 표는 기획 관점에서 각자가 맡는 결과물을 정리한 것이며, 다르면 README 4장을 따른다.

- 하루 전환·저장 데이터 계약은 김언호와 홍준우가 함께 정한다. 상태 변경·저장 복구·기술 통합은 김언호, 해당 입력·표시·화면 전환은 홍준우가 맡는다.
- 음원 목록·수급·출처·라이선스 정리 담당은 아직 정하지 않았다(🔴, 노션과 README의 기재가 달라 팀 확인 필요).
- 씬·핵심 프리팹의 편집 담당은 README 4장 「씬·프리팹 공동 작업」 표를 따른다.

> 이전 문장 정리 — “이펙트·사운드는 첫 루프 통합과 분리한다”(홍준우 항목)와 “🔴 씬·프리팹 담당은 README 4장과 함께 확정”은 README 4장에 사운드 책임 분리와 씬 담당표가 들어가기 전 문장이다. 현재는 위 표와 README 4장을 따른다.
