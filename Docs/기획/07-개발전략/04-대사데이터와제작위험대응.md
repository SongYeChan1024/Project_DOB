## 대사 데이터 설계

대사량이 큰 제작 비용이다. 일반 손님 반응은 프로토타입처럼 조각을 조합한다.
방문 대사는 손님 정보에서 실제 위험과 보여 줄 단서를 먼저 정한 뒤 원고를 고른다([방문 대사 생성](../04-핵심플레이/방문대사생성.md), [대사와 관찰 단서표](../05-데이터/대사와관찰단서표.csv)).
스토리의 첫 결과·파티 표식·현재 질문과 답장·생존 방식·출발 장면은 트리거 ID에 연결된 원고로 관리한다(데모 이후). 🔴 최종 대사와 질문·동료별 상태는 작성이 필요하다.

| 조각 | 프로토타입 기준 수량과 예시 |
| --- | --- |
| 축별 단서 대사 | 축마다 3개. 함정: "[[함정]]이 많대. 눈치가 빨라야 해." |
| 오늘의 이변 문장 | 축마다 1개. "바닥 틈의 [[열기]]가 오늘따라 거세다고 한다." |
| 맛 반응 | 요리 맛 점수 0~4마다 1개. "이거야! 딱 내가 원하던 맛이야." |
| 각오 한마디 | 부족 0~3마다 1개. "든든하긴 한데… 뭔가 하나 모자란 느낌이야." |
| 귀환 한마디 | 결과 등급마다 3개, 가장 모자란 축 이름을 끼워 넣는다. |
| 단골 사연 | 조각 42개(종족 15 · 직업 18 · 뼈대 9)를 조합. 종족·직업 조합마다 후보 3개, 단골마다 3단계(💡 누적 호감 9 · 21 · 36) |

원고의 `[[ ]]`는 클릭할 수 있는 단서의 범위를 지정한다. 대화가 열리면 평문으로 보이고, 플레이어가 찾아낸 표현에만 밑줄이 남는다.

## 제작 중 예상되는 문제와 대응

| 위험 | 대응 |
| --- | --- |
| 추리가 너무 쉽다 | 대사는 가장 큰 양수 축 하나만 가리킨다. 나머지는 층 지식과 수첩으로 채워야 한다. |
| 추리가 너무 어렵다 | 사전 탭, 보고에서 원인 공개, 수첩 누적, 💡 누적 호감 21 이상 단골은 단서 두 개 |
| 매번 같은 처방이 정답이 된다 | 오늘의 이변, 피곤, 직업 보정이 날마다 위험을 바꾼다. 돌발은 스토리 이후 안건으로 보류된 차후 확장이다(2026-11-25). |
| 재료가 떨어져 막힌다 | 기본 재료 무료·무제한으로 영업 재개를 보장한다. 양념·던전 재료·개량은 경제 선택으로 남기고 게임 오버·빚·재시작 비용을 새로 추가하지 않는다. |
| 자리 처방이 판정을 망가뜨린다 | 자리 효과를 돌발 보험 역할로 바꾸는 대안(돌발 도입 뒤의 차후 대안. [자리 안내와 효과](../04-핵심플레이/05-자리안내와효과.md)) |
| 3D일 이유가 약하다는 피드백 | [시제품 검증과 3D 선택 이유](01-시제품검증과3D선택이유.md)의 네 가지를 그레이박스 단계에서 먼저 보여 준다. |
