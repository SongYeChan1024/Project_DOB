# 단골 사연 조각

작성자: 송예찬 · 2026.10.29

## 0 기획 의도

손님 이름은 모두 무작위이고, 호감이 쌓인 과객이 단골이 된다. 같은 종족·직업의 단골이 여럿 생겨도(예: 하플링 전사 하루와 하플링 전사 솔) 사연이 겹치지 않도록, 사연을 통째로 쓰지 않고 조각을 조합한다. 사연은 꼭 감동적일 필요가 없다. 살짝 뭉클한 이야기와 피식 웃게 되는 이야기를 섞는다.

## 1 조합 규칙

| 항목 | 규칙 |
| --- | --- |
| 후보 배정 | 단골이 되면 그 종족·직업 조합에서 아직 배정되지 않은 후보(A·B·C) 하나를 받는다. 후보 3개를 모두 쓴 조합의 과객은 단골이 되지 않는다 |
| 1단계 (호감 3) | 뼈대 1단계 + 종족 조각의 **등장** 줄 |
| 2단계 (호감 7) | 뼈대 2단계 + 직업 조각의 **등장** 줄 |
| 3단계 (호감 12) | 뼈대 3단계 + 종족 조각의 **회수** 줄 + 직업 조각의 **회수** 줄 |
| 빈칸 | `{이름}`은 손님이 받은 무작위 이름. 주인공은 `주인장`으로 부른다 |
| 보상 물건 | 뼈대 단계마다 하나, 모두 9종. 식당 진열 선반의 장식이며 효과는 없다. C-3 지도만 효과가 있다 |

- 조각 수: 종족 5 × 후보 3 = 15, 직업 6 × 후보 3 = 18, 뼈대 후보 3 × 단계 3 = 9, 모두 42개
- 후보별 주제: **A 그리운 맛**(고향과 음식, 살짝 뭉클), **B 갚을 것**(빚·내기·약속, 유쾌), **C 아래층 소문**(허풍과 호기심, 유쾌)
- C 후보의 장소는 주인공의 5층 사건(StoryBTriggers)과 연결하지 않는다. 옛 파티의 생존·위치 단서로 읽히지 않게 쓴다.

## 5 조합 예시

### 하플링 전사 하루 — 후보 A

- **호감 3**: 하루: 주인장, 오늘 요리… 잠깐, 나 우는 거 아니야. 김이 눈에 들어간 거야. / 하루: 우리 마을은 하루 여섯 끼를 먹어. 다들 많다는데, 난 적다고 생각해. / 하루: 아무튼 여기 오면 좀 편해. 이거 받아 둬. 고향을 내가 그린 건데, 잘 그린 건 아니야. → 작은 고향 그림
- **호감 7**: 하루: 요즘 일이 잘 안 풀려. 정확히는 밥이 잘 안 풀려. / 하루: 방패를 들 힘은 있는데 배가 고프면 안 돼. 아래에선 육포뿐이라, 방패보다 육포가 더 단단해. / 하루: 그래서 내 수저를 여기 맡길게. 이제 여기가 내 자리야. 다른 손님이 쓰면 안 돼. → 이름 새긴 수저
- **호감 12**: 하루: 주인장, 중대 발표가 있어. / 하루: 고향에 편지했어. 일곱 번째 끼니를 찾았다고. / 하루: 여기 밥 먹고 내려간 날은 방패가 가볍더라. 기분 탓이래도 상관없어. / 하루: 결론은, 여기가 내 두 번째 고향이라는 거야. 밥은 첫 번째보다 맛있고. 이거 벽에 걸어 줘. 비뚤게 걸면 안 돼. → 고향 문장

### 하플링 전사 솔 — 후보 B

- **호감 3**: 솔: 주인장, 비밀 하나 말해도 돼? 나 갚을 게 있어. / 솔: 먼 길에 금방 지쳐서 일행한테 업어 달라고 했거든. 업힌 횟수만큼 빚이 됐어. 마흔두 번. / 솔: 이건 그때 쓴 차용증이야. 갖고 있으면 자꾸 생각나서 여기 맡길게. 잃어버리지 마. 아니, 잃어버려도 돼. → 구겨진 차용증
- **호감 7**: 솔: 갚을 방법을 찾았어. 아마도. / 솔: 동료랑 누가 더 오래 버티나 내기를 했는데 내가 이겼어. 문제는 둘 다 기절해서 아무도 못 봤다는 거야. / 솔: 이건 행운의 주사위야. 이걸로 갚을 거냐고? 아니, 이걸로 진 거야. 그래서 맡기는 거야. → 내기 주사위
- **호감 12**: 솔: 주인장, 드디어 다 갚았어! / 솔: 이제 내 걸음에 맞춰 길을 짜. 업어 달라는 말은 열 번만 해. / 솔: 재경기를 했어. 이번엔 증인을 세웠고, 졌어. 깔끔하게 갚았지. / 솔: 그 사람이 영수증 대신 편지를 써 줬어. '다신 안 빌려줌'이래. 감동적이지? 걸어 둬. → '다신 안 빌려줌' 편지

## 6 검토할 것

- 🟡 3단계는 종족 회수와 직업 회수를 이어 붙이므로 두 문장이 서로 이어지는지 조합별로 읽어 본다. 어색하면 회수 줄 사이에 뼈대의 연결 문장을 하나 넣는다.
- 🟡 말투는 모든 손님이 반말이다. 종족·직업별 말투 차이를 둘지 정한다.
