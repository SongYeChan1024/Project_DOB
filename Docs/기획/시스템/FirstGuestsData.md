## 0. 기획 의도

첫날 세 손님은 **판정 규칙을 하나씩 보여 주는 문제**다.

| 손님 | 가르치는 것 |
| --- | --- |
| 1 안내 | 위험 두 축(독·체력)을 찾고, 같은 효과를 같은 만큼 내면 막는다. 장비·외모도 단서다(마법사 열 −1은 1층에서 결과에 드러나지 않음) |
| 2 병행 연습 | 종족(외형)은 위험을 늘리고(하플링 체력 +1) 직업은 줄인다(사제 독 −1). 그래서 더 든든한 요리(고기 구이)가 필요하다 |
| 3 병행 연습 | 직업이 위험을 줄인다(전사 체력 −1). 남은 양념(마늘)을 아껴 써야 한다. 혼자 판단해 본다 |

💡 2026-11-24 수정: 손님 1의 직업 보정은 1층에 열 위험이 없어 결과로 체감되지 않으므로, 직업 보정의 체감은 손님 2·3이 맡는다.

## 2. 손님별 데이터와 판정

계산 순서는 노션 5장: 층 기본 위험 + 종족 약점 → 직업 보정 → 0 미만은 0 → 처방 효과와 비교, 부족 합으로 등급.

### 손님 1 — 안내 (확정 기준, tutorial-spec 그대로)

| 항목 | 값 |
| --- | --- |
| guestId | `tutorial_guest_01` |
| 이름 | 💡 하루 (`name_001`) |
| 종족 · 직업 | 인간 · 마법사 |
| 위험 계산 | 독 1 · 체력 1 · 열 0 → 인간 보정 없음 → 마법사 열 −1 (0 아래로 내려가지 않음) |
| **최종 위험** | **독 1 · 체력 1** |
| 정답 | 구운 빵(밀가루 2) + 마늘 → 해독 1 · 활력 1 · 감각 1 |
| 부족 | 0 → **대성공**, 전리품 3 |
| 마늘 재고 | 2 → 1 |

### 손님 2 — 병행 연습 (하플링 사제 · 2026-11-08 송예찬 선택)

| 항목 | 값 |
| --- | --- |
| guestId | `tutorial_guest_02` |
| 이름 | 💡 보리 (`name_002`) |
| 종족 · 직업 | 하플링 · 사제 |
| 위험 계산 | 독 1 · 체력 1 → 하플링 체력 +1 → 사제 독 −1 |
| **최종 위험** | **체력 2** (독 0) |
| 정답 | 고기 구이(고기 2) → 활력 3. 부족 0 → **대성공** |
| 다른 답 | 구운 빵 + 소금 → 활력 2. 부족 0 → 대성공 (소금 사용) |
| 흔한 실수 | 구운 빵만 → 활력 1. 부족 1 → 성공 |
| 마늘 실수 (E1) | 구운 빵 + 마늘 → 활력 1. 부족 1 → 성공. 마늘이 0이 되어 손님 3에 영향 |
| 마늘 실수 (E1-b) | 고기 구이 + 마늘 → 활력 3 · 해독 1. 부족 0 → 대성공(금화 11). 마늘이 0이 되어 손님 3에 영향 |
| 마늘 재고 | 정답이면 1 그대로 |

**왜 하플링인가:** tutorial-spec의 원래 안(인간 사제)은 최종 위험이 체력 1이라 구운 빵만으로도 대성공이다.
그러면 카드의 "고기 구이로 대비"가 꼭 필요한 선택이 아니다. 하플링이면 작은 키(외형)가 체력 +1을 뜻해서, 활력이 큰 고기 구이를 고를 이유가 생긴다.
새 위험 축은 늘지 않아 첫날은 여전히 독 · 체력 두 축만 다룬다.

### 손님 3 — 병행 연습 (tutorial-spec 그대로: 인간 전사)

| 항목 | 값 |
| --- | --- |
| guestId | `tutorial_guest_03` |
| 이름 | 💡 솔 (`name_003`) |
| 종족 · 직업 | 인간 · 전사 |
| 위험 계산 | 독 1 · 체력 1 → 인간 보정 없음 → 전사 체력 −1 |
| **최종 위험** | **독 1** (체력 0) |
| 정답 | 아무 요리 + 마늘 → 해독 1. 예: 구운 빵 + 마늘. 부족 0 → **대성공** |
| 흔한 실수 | 마늘 없이 → 해독 0. 부족 1 → 성공 |
| 마늘 재고 | 1 → 0 |

마늘이 해독을 낼 수 있는 유일한 수단이다. 첫날에는 해독이 있는 레시피(1층 재료 필요)가 아직 없다.

## 3. 첫날 결과 시나리오

| 플레이 | 손님 1 | 손님 2 | 손님 3 | 다음 아침 |
| --- | --- | --- | --- | --- |
| 모두 정답 | 대성공 | 대성공 | 대성공 | 1층 성공 이상 3번 → 2층 개방 조건 충족 (첫 플레이 범위에서는 2층 플레이 제외) |
| 손님 2에 구운 빵만 | 대성공 | 성공 | 대성공 | 원인 보고: "체력 1칸 모자람" |
| 손님 2에 마늘을 씀 (E1) | 대성공 | 성공 | 성공 | 손님 3 원인 보고: "독 1칸 모자람" |
| 손님 2에 고기 구이 + 마늘 (E1-b) | 대성공 | 대성공 | 성공 | 손님 3 원인 보고: "독 1칸 모자람". 금화 9 + 11 + 8 = 28 |

어떤 경우에도 부상이 나오지 않는다(최대 부족 1). 첫날에 실패를 강요하지 않는다는 tutorial-spec 5장 기준과 맞는다.
E1·E1-b는 막는 안내 대사 없이, 확정 화면의 차감 예정 재료(「마늘 1 → 0」)와 다음 아침 보고로 알린다(💡 송예찬 선택 2026-11-24, 팀 합의 전).

### 돌발 보험 참고 (첫날 돌발은 끔)

| 해법 | 활력 − 체력 위험 | 보험 |
| --- | --- | --- |
| 손님 1 구운 빵 + 마늘 | 0 | 없음 |
| 손님 2 고기 구이 | 1 | 있음 |
| 손님 2 구운 빵 + 소금 | 0 | 없음 |
| 손님 3 구운 빵 + 마늘 | 1 | 있음 |

정답끼리 보험 유무가 달라, 돌발을 켜면 「모두 정답 → 모두 대성공」이 보장되지 않는다. 보험 체감은 둘째 날 이후 `RESERVE_HELPED_RETURN` 장면으로 보여 준다.

### 💡 튜토리얼 고정 드롭 (`tutorialLootPlanId`)

일반 드롭 대신 아래 고정 계획을 쓴다. 희귀 재료(숲 송로)는 0개로 고정하고, 성공 등급이면 앞에서부터 2개만 준다.

마늘이 0이 되어도 둘째 날 해독 요리(숲버섯 수프 · 슬라임 젤리 샐러드)를 만들 수 있다. 레시피 해금 조건은 [재료·경제 검수](../밸런스/FirstPlayEconomy.md) 2장 #2와 함께 정한다.
