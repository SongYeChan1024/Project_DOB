## 1. 0일차 연습의 범위

플레이어 규칙: 손님 세 명에게 요리를 내고, 다음 날 아침 결과를 들은 뒤 다시 영업을 시작한다.

| 구분 | 포함 | 제외 (후속 단계) |
| --- | --- | --- |
| 흐름 | 타이틀 → 연습 영업 → 마감 → 다음 아침 귀환 보고 → 준비 → 재영업 시작 | 5층, 엔딩 이후 영업 |
| 손님 | 첫 방문부터 무작위 생성, 안내 1명 + 병행 연습 2명 (총 3명), 1층 | 단골 사연·호감 해금 장면, 2층 이상 |
| 판정 | 축별 위험·효과·최종 부족·결과 등급 | 세부 세팅 값 |
| 조리 | 중앙 조리도구·좌우 요리도구, 재료와 양념 넣기·빼기·확정·6초 자동 조리·서빙 | 22레시피 전체, 희귀 재료 |
| 자리 | 💡 자리 안내 조작만 포함, 자리 효과 없음 (송예찬 선택 2026-11-24, 팀 합의 전) | 자리 효과(이후), 효과 소품 구매·자유 배치 |
| 돌발 | 💡 돌발 없음 (`tutorialRandomHazardsEnabled = false`, 송예찬 선택 2026-11-24, 팀 합의 전) | 돌발·활력 여유 보험 체감(이후) |
| 개인 취약점 | 연습 손님 3명 제외 | 처음 소개하는 원고는 [손님 대사와 단서 원고](손님대사와단서원고.md#3-개인-취약점-첫-소개) |
| 보고 | 결과 도장·한마디·축별 결과·전리품·수첩 기록 | 양피지 회상의 추가 편린 (첫 독백 1개는 포함) |
| 저장 | 일차를 넘기는 시점 자동 저장, 누른 시점 수동 슬롯 저장·불러오기, Esc 메뉴 다섯 항목 ([저장 기준](../09-승인과제작기준/02-제작순서와저장기준.md#저장-기준), 2026-11-25) | 후속 스토리 저장 세부 |

목표 길이: 연습 영업 💡 5~8분. 재영업은 **시작 시점까지만** 범위로 본다. 예전 카드의 「임시 엔딩」은 현재 [데모 엔딩](09-성장과데모엔딩.md#데모-엔딩)으로 바뀌었다.

## 3. 연습 손님 기준

첫 방문부터 손님을 무작위로 뽑는다. 1명에게 조작을 안내한 뒤 2명을 함께 응대하는 순서는 유지한다. 생성한 손님의 이름·외형·직업과 주문을 응대부터 귀환까지 이어 쓴다. 이름 규칙은 [손님 이름과 재방문](../03-세계관과스토리/손님이름과재방문.md)에 있다.

고정 이름·직업을 가진 [시험 손님 세 명](../05-데이터/시험손님과판정데이터.md)은 단서·요리·판정을 같은 조건에서 비교할 때만 쓴다. 실제 손님 조건에 맞는 문구는 [손님 대사와 단서 원고](손님대사와단서원고.md), 장면별 조작과 완료 기준은 [첫 영업 장면 연출](../06-인터페이스/첫영업장면연출.md)에 있다.

## 4. 성공 확인표 (0일차 연습)

각 항목은 실제 실행으로 확인한다. 문서 대조만으로 통과 처리하지 않는다. S2~S9는 1일차 본영업 루프에도 같은 기대 결과로 쓸 수 있다. 다만 1일차에는 연습 안내가 없고, 손님은 3명이다(2일차부터 재방문 + 입소문 신규).

| ➕ S1-1 | 서로 다른 손님 조합으로 새 게임 시작 | 어느 조합이든 첫 응대·조리·귀환이 이어지며 어제의 손님과 오늘의 보고가 일치함 | 홍준우 · 김언호 |
| S2 | 첫 손님에게 E 응대 | 1인칭 응대 구도, 초상·단서·대사 표시. 응대 중에도 손님 입장·대기와 조리는 흐름(Esc에서만 정지, FeatureManagerMap F2) | 홍준우 |
| ➕ S2-1 | ‘슬라임 점액’ 클릭 → 같은 말 재클릭 → 같은 층 위험을 가리키는 ‘따끔’ 클릭 | 첫 클릭에 밑줄·기록·독 1칸이 생긴다. 재클릭하면 그대로다. ‘따끔’까지 찾으면 밑줄은 두 개, 독은 **1칸**이다(원인별 칸 확정, [4-4](04-단서추리와수첩.md#수첩-칸은-원인별로-한-번-센다)). 예전 표현 개수 방식이었다면 2칸이다. | 홍준우 · 김언호 |
