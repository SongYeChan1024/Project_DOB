# 4-5. 자리 안내와 효과

[← 4장 목차](README.md) · [메인 기획서](../메인기획서.md)

재설계안의 「손님에게 맞는 자리를 선정해서 배치한다」를 규칙으로 옮겼다. 식당의 자리는 주변 사물 때문에 붙는 효과가 다르다. 손님이 앉아 쉬는 동안 몸이 그 환경에 익숙해진다는 설정이다.

## 첫 완성본의 범위

| 포함 | 확장 범위로 남김 |
| --- | --- |
| 고정 설치 지점의 소품과 연결 좌석으로 효과 적용 | 자유 배치·위치·방향·거리 |
| 구매 전에 적용 좌석·효과·가격 표시 | 여러 소품 효과의 중첩 |
| 시작 소품·가격·해금 순서는 시험 데이터로 관리 | 인접 판정 |

## 자리 효과 (예시)

| 자리 | 효과 +1 | 이유와 연출 |
| --- | --- | --- |
| 난로 옆 | 방한 | 몸을 데운다. 불꽃이 보인다 |
| 바람 드는 창가 | 내열 | 더위에 강해진다. 커튼이 흔들린다 |
| 빛나는 장식 | 야광 | 은은하게 빛나는 장식. 어둠 속에서도 앞이 보인다 |
| 약초 화분 옆 | 해독 | 약초 향이 해독을 돕는다 |
| 푹신한 소파 | 활력 | 푹 쉰다. 쿠션이 놓여 있다 |
| 조용한 칸막이석 | 감각 | 소리에 귀가 트인다. 칸막이가 있다 |

## 규칙

- 자리 하나에는 손님 한 명만 앉는다. 같은 효과가 필요한 손님이 둘이면 한 명은 자리로, 다른 한 명은 양념으로 메워야 한다.
- 좌석 증설(3석 → 6석)과 효과 소품 해금은 별개의 개량이다. 💡 한 좌석에 한 종류의 소품 효과를 적용하는 초기안을 시험한다.
- 연결 좌석을 미리 보여 주고, 숨은 거리 판정으로 효과가 달라지지 않게 한다.
- 💡 목적지와 관찰·대화를 확인한 뒤 자리를 정하는 초기안으로 검증한다. 자리 변경·효과 확정 시점은 가안이며, 조리 확정 때 효과 스냅샷을 저장하는 방식을 시험한다. 확정 뒤 자리를 바꿔 효과를 중복으로 더하지 않는다.
- 🟡 자리 효과 +1은 양념 하나와 같은 시험값이다. 판정과 요리 선택에 미치는 영향을 검증한다.
- 💡 0일차 연습(예전 「첫날」)에서는 자리 안내 조작만 가르치고 자리 효과는 주지 않는 안이다(송예찬 선택 2026-11-24, 팀 합의 전). 해독 좌석이 있으면 시험 손님 3을 마늘 없이 풀 수 있어 학습 의도가 사라지기 때문이다.

좌석 가격과 개량 순서는 [4-9 가게 개량](09-성장과데모엔딩.md#가게-개량)에 있다.

## 공간과 동선

원본 그림 4(식당 공간·동선 제작 참고)는 [구글 메인기획서](https://docs.google.com/document/d/1nFDNT7zw3tflOq4N4xJNqzioT0eQcbbVXVVCzUswXOE)에 있다. 입장(1) → 대화 위치(2) → 좌석(3) → 던전 출구(6) 순서이고, 주방(4)과 완성 접시 위치(5)는 플레이어 동선으로 연결한다. 좌석 수·크기·거리는 예시다.
