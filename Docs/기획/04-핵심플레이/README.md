# 4. 핵심 플레이 구조

[← 메인 기획서](../메인기획서.md)

손님의 말과 차림에서 위험을 읽고, 자리와 요리로 처방해 내려보낸 뒤, 다음 날 아침 결과를 듣는다. 결과는 손님 한 명의 호감과 가게의 입소문으로 이어져 다음 영업을 바꾼다.

```text
준비(시장) → 응대·추리 → 자리 → 요리 → 서빙 → 식후 반응·방명록 → 마감·정산·자동 저장 → 다음 아침 귀환 보고 → 준비 …
```
