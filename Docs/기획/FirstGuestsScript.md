# 첫날 손님 대사 · 단서 원고

상태: 💡 원고 초안. 노션 작업 보드 「제작 | 03 관찰 단서·주문·튜토리얼 대사」의 결과물이다.
카드 본문은 비어 있었다. 손님 설정은 [첫날 손님 데이터](FirstGuestsData.md)(기획 02)의 선택안(손님 2 하플링 사제)을 따른다. 그 안이 바뀌면 이 원고도 같이 고친다.

기준: 노션 4-4장 대사 규칙, 7-7장 대사 조각, 17장 ③(튜토리얼 수정) · ⑤(개인 취약점), tutorial-spec V0.01 4장 단계표.

## 1. 손님별 원고

### 손님 1 — 하루 (인간 · 마법사) · 최종 위험 독 1 · 체력 1

| 장면 | 원고 |
| --- | --- |
| 입장 | "여기가 계단 중간에 있다는 식당이구나. 내려가기 전에 한 끼 부탁해." |
| 주문 대화 | "오늘은 1층 슬라임 숲. [[슬라임 점액]]이 튀면 [[따끔]]하더라. 돌아오는 [[길도 멀고]]." |
| 관찰 — 직업 | 지팡이, 소매 끝이 살짝 그을린 로브 → 마법사: 불에 익숙하다 (열 −1) |
| 관찰 — 컨디션 | 허리를 펴고 서 있다, 땀방울 없음 → 피곤하지 않음 |
| 사전 도움말 | 점액 · 따끔 → **독** / 먼 길 · 허기 → **체력** |
| 각오 (부족 0) | "이 정도면 끝까지 버틸 수 있겠어." |
| 각오 (부족 1) | "든든하긴 한데… 뭔가 하나 모자란 느낌이야." (7-7 예시) |
| 귀환 (대성공) | "점액이 튀어도 멀쩡했어. 돌아오는 길도 하나도 안 지쳤고." |

### 손님 2 — 보리 (하플링 · 사제) · 최종 위험 체력 2

| 장면 | 원고 |
| --- | --- |
| 입장 | "의자가 좀 높네… 괜찮아, 올라갈 수 있어." |
| 주문 대화 | "1층에 약초 캐러 가. 다리가 짧아서 그런지 [[먼 길]]만 가면 금방 [[배가 고파]]. 넉넉하게 먹고 싶어." |
| 관찰 — 종족 | 아이 같은 키, 의자에 올라앉음 → 하플링: 몸이 작아 먼 길에 지친다 (체력 +1) |
| 관찰 — 직업 | 목에 건 성표, 작은 향로 → 사제: 정화의 가호 (독 −1) |
| 관찰 — 컨디션 | 표정이 밝다 → 피곤하지 않음 |
| 💡 보조 대사 | "점액? 그 정도는 기도 한 번이면 괜찮아." — 독은 사제 가호로 막힌다는 힌트. 가장 큰 축 규칙의 예외라 💡 |
| 각오 (부족 0) | "배가 든든하니까 어디까지든 걸을 수 있겠어." |
| 각오 (부족 1) | "음… 가다가 한 번은 쉬어야겠다." |
| 귀환 (대성공) | "끝까지 걸어갔는데도 배가 안 고팠어. 약초도 잔뜩 캤어!" |

### 손님 3 — 솔 (인간 · 전사) · 최종 위험 독 1

| 장면 | 원고 |
| --- | --- |
| 입장 | "빨리 먹고 빨리 내려갈게. 힘은 남아돌거든." |
| 주문 대화 | "슬라임 숲 끝까지 밀고 들어갈 거야. 걸어 다니는 건 문제없는데, [[점액]]이 갑옷 틈으로 스며들면 [[따끔]]해서 말이지." |
| 관찰 — 직업 | 큰 방패, 굵은 팔 → 전사: 체력이 좋다 (체력 −1) |

| 각오 (부족 1) | "든든하긴 한데… 뭔가 하나 모자란 느낌이야." |
| 귀환 (대성공) | "갑옷 틈이 끈적했는데도 하나도 안 따끔했어." |
| 귀환 (성공, 마늘 부족) | "다녀오긴 했는데, 점액 맞은 데가 아직 좀 따끔해." |

맛 반응 대사는 7-7의 맛 점수별 조각을 그대로 쓴다. 취향이 정해지면(기획 02 🔴) 다시 확인한다.

## 2. 튜토리얼 안내 문구 (T00~T13)

단계 번호는 tutorial-spec 4장. 안내 문구는 짧게 쓰고, 설명 화면에 시간 제한을 두지 않는다.

| 단계 | 안내 문구 |
| --- | --- |
| T00 | "손님을 살펴보고, 돌아올 준비를 도와주세요." |
| T01 | "WASD로 움직여 입구의 손님에게 다가가세요." |
| T02 | "E를 눌러 손님을 맞이하세요." |
| T03 | "밑줄 친 말이 단서예요. 손님이 갈 곳의 위험을 돌려 말하고 있어요. 모르는 표현은 수첩 사전에서 찾을 수 있어요." |
| T03 보조 | "지팡이를 든 마법사는 불에 익숙해요. 장비와 외모도 단서예요." |
| T04 | "손님을 자리로 안내하세요. 다음에는 자리가 준비를 도울 수도 있어요." |
| T05 | "주방에서 E를 눌러 요리를 고르세요." |
| T06 | "밀가루를 두 번, 마늘을 한 번 넣어 보세요. 아래에 요리 효과가 보여요. 점액에는 해독, 먼 길에는 활력이에요." |
| T07 | "확정하면 조리가 시작돼요. 넣은 양념은 이때 줄어들어요." |
| T08 | "조리는 혼자 진행돼요. 기다리지 말고 움직여도 돼요. **손님과 이야기하거나 수첩을 보는 동안에도 조리는 계속돼서, 다 읽기 전에 완성될 수 있어요.**" |
| T09 | "완성된 접시를 E로 들고, 그 접시를 주문한 손님에게 가져다주세요." |
| T10 | "이번엔 두 손님이 함께 왔어요. 한 요리를 조리하는 동안 다른 손님과 이야기할 수 있어요. **이야기하는 사이 조리가 끝나면, 화면을 닫았을 때 접시가 준비돼 있어요.**" |
| T10 보조 | "양념은 남은 만큼만 쓸 수 있어요. 기본 재료(밀가루·감자·고기)는 얼마든지 써도 돼요." |
| T11 | "오늘 영업을 마칠까요? 손님들의 결과는 내일 아침 알 수 있어요." |
| T12 | "돌아온 손님의 이야기를 들어 보세요. 무엇을 막았고 무엇이 모자랐는지 알려 줘요." |
| T13 | 안내 문구 없음. 양피지 그림과 카엘의 짧은 독백만 보여 준다 (원고는 기획 05) |

굵게 표시한 T08 · T10 문장은 17장 ④ "대화 중에도 조리 진행" 결정을 반영한 것이다.

## 3. 둘째 날 개인 취약점 소개

둘째 날 처음 만나는 손님 중 개인 취약점이 있는 첫 손님에게 한 번만 쓴다(17장 ⑤). 그림 레이어와 대사를 함께 쓰고, 색만으로 구분하지 않는다.

| 축 | 그림 레이어 | 손님 대사 (예) |
| --- | --- | --- |
| 독 | 기침 · 창백한 얼굴 | "콜록… 요즘 [[목이 칼칼]]해. 그래도 내려가야지." |
| 열 | 화상 자국 | "지난번에 [[덴 자리]]가 아직 화끈거려." |
| 냉기 | 떨림 · 목도리 | "으, 나는 원래 [[추위]]를 많이 타서." |
| 어둠 | 찡그린 눈 | "눈이 침침해서 [[어두운 데]]선 앞이 잘 안 보여." |
| 함정 | 절뚝거림 | "다리를 좀 [[삐었는데]], 발밑을 조심해야겠지." |

안내 문구 (한 번만):
> "이 손님만의 약한 곳이 보여요. 종족·직업과 별개로, 그만큼 더 대비해야 해요. 알아낸 약한 곳은 수첩에 남아요."

- 💡 개인 취약점 대사는 가장 큰 축 규칙과 별개로 소개 손님에게만 덧붙이는 안이다. 이후 손님은 그림 레이어로만 알려 줄지 팀이 정한다.
- 열 · 함정 대사는 지난 부상 흔적처럼 읽힐 수 있다. tutorial-spec 2-2장은 지난 탐험 흔적을 이번 위험에 자동으로 더하지 않으므로, 그림 레이어 쪽에서 "지금 약한 곳"으로 구분되는지 아트와 확인한다.
