# 주요 타깃과 사용자 니즈

[← 2. 타겟 사용자](README.md) · [메인 기획서](../메인기획서.md)

## 누구를 위한 게임인가

| 구분 | 대상 | 상태 |
| --- | --- | --- |
| 주 타깃 | 25~39세, PC에서 대화·추리·가게 성장을 즐기는 이용자 | 2026-10-30 노션 17장 결정 ① ([승인 결정과 현재 상태](../09-승인과제작기준/01-승인결정과현재상태.md)) |
| 보조 타깃 | 같은 취향의 15~24세와 40세 이상 | 표현 강도는 유혈 대신 붕대·지친 표정으로 전달 |
| 플레이 테스트 모집 | 25~34세와 35~39세를 함께 모집 | |

## 세부 타깃

| 이런 게임을 좋아하는 사용자 | 이 게임에서 얻는 것 |
| --- | --- |
| 대화로 손님을 읽는 게임 — 손님의 이야기를 듣고 알맞은 것을 내주는 경험 | 판단의 결과가 다음 날 귀환 보고와 부상으로 분명하게 돌아온다. |
| 단서를 대조해 판정하는 게임 — 흩어진 정보를 맞춰 하나의 결론을 내리는 재미 | 위험 여섯 축이라는 고정된 틀 안에서 단서를 맞추므로 무엇을 찾아야 하는지가 늘 분명하다. |
| 가게와 관계를 키우는 경영 게임 — 번 돈으로 가게를 넓히고 단골과 친해지는 과정 | 가게 개량, 단골의 [단골] 태그와 사연이 하루하루 쌓인다(사연 재생은 데모 완성 후 범위). |

## 사용자가 바라는 것과 이 게임의 대응

| 니즈 | 대응 방식 | 자세한 규칙 |
| --- | --- | --- |
| 읽는 재미가 있었으면 한다 | 손님은 위험을 돌려 말한다. 플레이어가 표현을 찾아 클릭하면 밑줄이 생기고 수첩에 어떤 위험의 단서인지 기록된다. 같은 원인을 가리키는 표현을 여러 개 찾아도 칸은 한 번만 오른다. | [단서 추리와 수첩](../04-핵심플레이/04-단서추리와수첩.md) |
| 틀려도 왜 틀렸는지 알고 싶다 | 귀환 보고에서 축마다 "막아냈다 / N칸 모자랐다"를 보여 주고, 그 층의 위험을 수첩에 기록한다. | [귀환 보고와 재방문](../04-핵심플레이/07-귀환보고와재방문.md) |
| 기억할 것이 너무 많지 않았으면 한다 | 수첩이 알아낸 것을 적어 둔다. 준비 화면 시안에는 던전·단골·사전 탭이 있다. | [단서 추리와 수첩](../04-핵심플레이/04-단서추리와수첩.md) |
| 손이 바쁜 요리 게임은 피곤하다 | 조리는 확정 뒤 6초 자동이다. 바쁨은 손 빠르기가 아니라 여러 손님을 돌리는 순서에서 나온다. | [주방과 서빙](../04-핵심플레이/06-주방과서빙.md) |
| 진행이 막히면 안 된다 | 게임 오버는 원래 기획에 없다. 기본 재료(밀가루·감자·고기)는 무료·무제한이라 자원이 바닥나도 영업을 이어 간다. 양념·던전 재료·가게 개량은 경제 선택으로 남긴다. | [첫 영업 재료와 경제](../05-데이터/첫영업재료와경제.md) |
