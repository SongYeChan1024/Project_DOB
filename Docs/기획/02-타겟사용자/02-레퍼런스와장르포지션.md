> **장르 포지션** — 대화 추리(메인) + 식당 경영 + 3D 공간 배치

## 구조를 참고한 게임

| 게임 | 구조 | 이 게임이 가져오는 것 |
| --- | --- | --- |
| Coffee Talk | 손님의 사정을 대화로 듣고 음료를 만들어 준다 | 대화로 손님을 읽고 먹을 것으로 답하는 구조 |
| Papers, Please | 서류의 단서를 대조해 통과 여부를 판정한다 | 정해진 틀 안에서 단서를 대조하는 판정 |
| Strange Horticulture | 단서를 모아 식물을 알아내고 손님에게 내준다 | 기록이 쌓이며 추리가 쉬워지는 성장 |
| Recettear 류 상점 경영 | 모험가에게 물건을 팔고 그들이 던전에 간다 | 손님이 던전에 들어가는 가게라는 무대 |
