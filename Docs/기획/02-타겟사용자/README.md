## 2-1. 주요 타겟

주 타깃은 25~39세로, PC에서 대화·추리·가게 성장을 즐기는 이용자다.<br>
보조 타깃은 같은 취향의 15~24세와 40세 이상이다.<br>
표현 강도는 유혈 대신 붕대·지친 표정으로 전달한다.<br>
플레이 테스트는 25~34세와 35~39세를 함께 모집한다.

## 2-2. 세부 타겟

1. 대화로 손님을 읽는 게임을 좋아하는 사용자

손님의 이야기를 듣고 알맞은 것을 내주는 경험을 좋아하는 사용자이다.<br>
본 프로젝트는 그 판단의 결과가 손님의 귀환 보고와 부상으로 분명하게 돌아온다.

2. 단서를 대조해 판정하는 게임을 좋아하는 사용자

흩어진 정보를 맞춰 하나의 결론을 내리는 데서 재미를 느끼는 사용자이다.<br>
본 프로젝트는 여섯 축이라는 고정된 틀 안에서 단서를 맞추므로, 무엇을 찾아야 하는지가 늘 분명하다.

3. 가게와 관계를 키우는 경영 게임을 좋아하는 사용자

번 돈으로 가게를 넓히고, 단골과 친해지며 이야기가 열리는 과정을 좋아하는 사용자이다.

## 2-3. 타겟 니즈

| 니즈 | 본 프로젝트의 대응 방식 |
| --- | --- |
| 읽는 재미가 있었으면 한다 | 손님은 위험을 돌려 말한다.<br>플레이어가 그 표현을 찾아 클릭하면 밑줄이 생기고 수첩에 어떤 위험의 단서인지 기록된다 |
| 틀려도 왜 틀렸는지 알고 싶다 | 귀환 보고에서 축마다 "막아냈다 / N칸 모자랐다"를 보여 주고, 그 층의 위험을 수첩에 기록한다 |
| 기억할 것이 너무 많지 않았으면 한다 | 수첩(던전 · 단골 · 사전)이 알아낸 것을 모두 적어 둔다 |
| 손이 바쁜 요리 게임은 피곤하다 | 조리는 자동이다.<br>바쁨은 손 빠르기가 아니라 여러 손님을 돌리는 순서에서 나온다 |
| 진행이 막히면 안 된다 | 게임 오버는 원래 기획에 없다.<br>기본 재료(밀가루·감자·고기)를 무료·무제한으로 사용해 자원 소진으로 진행이 막히지 않게 한다.<br>양념·던전 재료·가게 개량은 경제 선택으로 유지한다. |
