## 1. 첫 플레이 명세

플레이어 규칙: 첫날 손님 세 명에게 요리를 내고, 다음 날 아침 결과를 들은 뒤 다시 영업을 시작한다.

| 구분 | 첫 플레이에 포함 | 첫 플레이에서 제외 (후속 단계) |
| --- | --- | --- |
| 흐름 | 타이틀 → 첫 영업(튜토리얼) → 마감 → 다음 아침 귀환 보고 → 준비 → 재영업 시작 | 임시 엔딩, 5층, 엔딩 이후 영업 |
| 손님 | 안내 1명 + 병행 연습 2명 (총 3명), 1층 | 단골 사연·호감 해금 장면, 2층 이상 |
| 판정 | 축별 위험·효과·최종 부족·결과 등급 | 세부 세팅 값 |
| 조리 | 재료 직접 투입·양념 선택·확정·6초 자동 조리·서빙 | 22레시피 전체, 희귀 재료 |
| 자리 | 첫날 자리 처방 포함 (🔴 6장 결정 필요) | 효과 소품 구매·자유 배치 |
| 개인 취약점 | 첫날 3명 제외 | 둘째 날 첫 소개 원고는 기획 03 카드 |
| 보고 | 결과 도장·한마디·축별 결과·전리품·수첩 기록 | 양피지 회상의 추가 편린 (첫 독백 1개는 포함) |
| 저장 | 준비 완료·마감·귀환 결과 확정 자동 저장 | ⑥ 저장 경계 세부는 검토 대기 |

목표 길이: 첫 영업(튜토리얼) 💡 5~8분. 재영업은 **시작 시점까지만** 첫 플레이 범위로 본다.

## 2. 단계별 흐름

| 순서 | 단계 | 씬 조합 | 플레이어가 하는 일 | 다음 단계로 넘어가는 조건 |
| --- | --- | --- | --- | --- |
| 1 | 타이틀 | Title | 새로 시작 | 타이틀 화면의 각 버튼 작동 여부 |
| 2 | 튜토리얼 실행 | Restaurant + Gameplay + Tutorial | 첫 시작이면 튜토리얼 자동 실행. 이동·E 응대 조작 안내 | 튜토리얼 조합 로드 완료, 첫 손님 입장 |
| 3 | 손님 안내 | Restaurant + Gameplay + Tutorial | E 응대 → 단서 확인 → 구운 빵+마늘 조리 → 서빙 | 첫 손님 서빙 완료 |
| 4 | 병행 연습 | 같음 | 두 손님 동시 응대. 둘째 고기 구이, 셋째 마늘 해법 | 접수한 주문 모두 처리 |
| 5 | 마감 | 같음 | 매출·지출·던전에 있는 손님 확인 | 마감 확인 |
| 6 | 다음 아침 귀환 보고 | ReturnReport | 세 손님 결과 확인 → 카엘 양피지 독백 | 모든 보고와 필수 정산 처리 (MorningReportsCompleted) |
| 7 | 준비 | 🔴 준비 화면 씬 위치 결정 필요 | 재료·양념 확인, 수첩 확인 | 준비 완료 |
| 8 | 재영업 시작 | Restaurant + Gameplay | 일반 영업 시작 | 첫 손님 입장 |

## 3. 첫날 손님 기준

상세 데이터는 기획 02 카드에서 작성한다.

| 손님 | 역할 | 확정된 기준 | 작성 필요 |
| --- | --- | --- | --- |
| 1 | 안내 | 비피곤 1층 인간 마법사, 독 1·체력 1, 구운 빵+마늘 | 대사·단서 원고 (기획 03) |
| 2 | 병행 연습 | 고기 구이로 대비 | 종족·직업·위험 축 |
| 3 | 병행 연습 | 시작 마늘 2개 중 두 번째로 해결 | 종족·직업·위험 축 |

시작 마늘이 2개이므로 둘째 손님에게 마늘을 쓰면 셋째 손님 해법이 깨진다. 이 경우의 처리를 5장 예외 표 E1에 둔다.

## 4. 성공 확인표

각 항목은 실제 실행으로 확인한다. 문서 대조만으로 통과 처리하지 않는다.

| 번호 | 확인 내용 | 기대 결과 | 확인 담당 |
| --- | --- | --- | --- |
| S1 | 타이틀에서 새로 시작 | 튜토리얼 조합 로드, 카메라·EventSystem·캐릭터 각 1개 | 홍준우 · 김언호 |
| S2 | 첫 손님에게 E 응대 | 1인칭 응대 구도, 초상·단서·대사 표시, 영업 시간 정지 | 홍준우 |
| S3 | 구운 빵+마늘 확정 | 마늘 1개 소비, 6초 자동 조리 시작, 이동 가능 | 김언호 |
| S4 | 조리 잔여 4초에 다른 손님 응대 10초 | 응대 중 완성, 응대를 닫으면 지정 주문 접시 ready | 김언호 · 홍준우 |
| S5 | 접시를 지정 손님에게 서빙 | 맛 반응·각오 한마디·금화 지급, 손님이 계단으로 내려감 | 김언호 |
| S6 | 세 손님 처리 후 마감 | 새 접수 종료, 매출·지출·던전 손님 목록 표시 | 홍준우 |
| S7 | 다음 아침 보고 | 손님별 결과 도장·한마디·축별 결과·전리품·수첩 기록 | 홍준우 · 김언호 |
| S8 | 보고 후 독백 | 카엘 기준 양피지 독백 1회 재생 | 홍준우 · 이기혁 |
| S9 | 준비 → 재영업 | 재고·금화·수첩이 보고 결과대로 유지되어 영업 시작 | 김언호 |
| S10 | 전체 시간 | 첫 영업 5~8분 안 (플레이 테스트 측정) | 송예찬 |

## 5. 예외 확인표

예외는 기본적으로 「아무 일도 일어나지 않는」 쪽으로 처리한다 (README 7장).

| 번호 | 상황 | 기대 결과 | 상태 |
| --- | --- | --- | --- |
| E1 | 둘째 손님에게 마늘을 써서 셋째 손님용 마늘이 없음 | 기본 재료로 조리 가능, 결과는 부족으로 보고. 진행은 막히지 않음 | 안내 대사로 막을지 결정 필요 |
| E2 | 틀린 요리를 서빙 | 서빙은 성공, 다음 아침 「N칸 모자랐다」로 보고. 게임 오버 없음 | 결정 사항 기반 |
| E3 | 손님을 돌려보냄 | 던전에 가지 않음, 귀환 보고 없음 | 튜토리얼 중 돌려보내기 허용 여부 |
| E4 | 같은 확정·서빙 버튼 반복 입력 | 재료 1회 소비, 접시 1개, 금화 1회 | 김언호 확인 |
| E5 | 다른 손님에게 접시 전달 시도 | 거절, 접시 유지 | 김언호 확인 |
| E6 | 응대·수첩을 겹쳐 열고 하나만 닫음 | 남은 정지 사유가 유지됨 | 김언호 · 홍준우 확인 |
| E7 | 보고 화면 재진입·되돌아가기 | 보상·호감·수첩 기록이 중복 지급되지 않음 | 김언호 확인 |
| E8 | 영업 중 게임 종료 후 불러오기 | 가안: 영업 시작 시점으로 복귀 | ⑥ 저장 경계 검토 대기 |
| E9 | 보고 정산 후 독백 전에 종료 | 정산 중복 없이 독백 재생 대기 | 4-10 저장 순서 따름 |
| E10 | 씬 전환 중 반복 요청 | 무시, 조합 잔류 없음 | 씬 분리 PlayMode 검사로 일부 확인됨 |
| ➕ E11 | 금화·양념이 0인 채로 재영업 | 기본 재료 요리로 영업을 계속할 수 있음. 게임 오버 없음 | 결정 사항 기반 (최신 결정) |
| ➕ E12 | 양피지 독백 생략 | 튜토리얼 완료·보상·필수 사실 유지, 재처리 없음 | tutorial-spec 6장 |
