# 첫 플레이 범위와 완료 기준

작성자: 송예찬 · 2026-11-07

상태: 💡 기획 초안. 작업 보드 「제작 | 01 첫 플레이 범위·완료 기준 확정」의 결과물이다.
김언호·홍준우가 읽고 범위에 동의하면 💡를 지운다. 구현 완료나 실행 검증 결과가 아니다.

기준 문서: 팀 노션 「기획」 17장, [최신 결정](CurrentDecisions.md), [메인 기획서 동기화본](MainPlanning.md), tutorial-spec V0.01(노션 첨부), [씬 분리 설계](../개발/SceneComposition.md).
이 문서는 새 규칙이나 수치를 만들지 않는다. 기존 결정 중 **첫 플레이에 무엇을 넣고 무엇을 빼는지**와 **어떻게 되면 끝났다고 보는지**만 정한다.

---

## 0. 기획 의도

첫 플레이의 목표는 게임의 한 바퀴가 실제로 돌아가는지 확인하는 것이다.

> 손님을 읽는다 → 요리로 대비한다 → 다음 아침 결과를 듣는다 → 그 결과로 다음 영업의 선택을 바꾼다.

이 바퀴가 재미있고 이해되는지 6번 작업(첫 루프 플레이 테스트)에서 확인한다. 그 전에 5층·단골 사연·스토리·엔딩은 만들지 않는다.

## 1. 플레이어 규칙 (첫 플레이에서 배우는 것)

1. 손님에게 다가가 E를 누르면 모습을 살피고 이야기를 들을 수 있다.
2. 손님이 갈 곳의 위험을 알아내고, 같은 종류의 효과를 같은 만큼 내는 음식을 만든다.
3. 재료를 넣고 확정하면 조리는 자동으로 된다. 그동안 다른 손님을 받을 수 있다.
4. 결과는 다음 아침 돌아온 손님이 알려 준다. 틀려도 게임은 끝나지 않는다.

## 2. 흐름 — 첫 플레이 한 바퀴

```text
Title ─새 게임─▶ 1일차 튜토리얼 영업 ─마감─▶ 2일차 아침 귀환 보고 ─▶ 준비 ─▶ 2일차 영업(재영업) ─마감─▶ 3일차 아침 귀환 보고 ─▶ 저장 · Title 복귀
             (Restaurant+Gameplay+Tutorial)    (ReturnReport)                    (Restaurant+Gameplay)               (ReturnReport)
```

| 구간 | 씬 조합 | 하는 일 | 끝나는 조건 |
| --- | --- | --- | --- |
| F0 타이틀 | Title | 새 게임 / 이어하기 | 새 게임은 F1, 이어하기는 마지막 저장 지점 |
| F1 1일차 튜토리얼 | Restaurant + Gameplay + Tutorial | tutorial-spec T00~T11. 안내 1명 + 병행 연습 2명 | 세 손님을 서빙했거나 안전하게 돌려보내고 마감 확인 |
| F2 2일차 아침 보고 | ReturnReport | 세 손님의 결과 도장·대비 내역·전리품·수첩·짧은 독백, 첫 양피지 편린(T12~T13) | 모든 보고 확인 → 튜토리얼 완료 저장 |
| F3 준비 | Restaurant + Gameplay (준비 단계) | 받은 재료·열린 레시피 확인, 양념 구매 | 영업 시작 확인 |
| F4 2일차 영업 | Restaurant + Gameplay | 안내 없이 일반 손님 응대. 둘째 날 첫 손님에게 개인 취약점 소개 1회 | 영업 시간 종료 → 접수한 주문 마무리 → 마감 |
| F5 3일차 아침 보고 | ReturnReport | 2일차 손님들의 결과. 1일차와 다른 결과(간신히·부상 등)가 나올 수 있음 | 보고 확인 → 저장 → Title 복귀 또는 다음 준비 |

- 💡 첫 플레이의 끝을 **F5 보고 확인 후 저장**으로 둔다. "결과를 보고 다음 선택을 바꾸는" 경험이 F2→F4에서 한 번, F5에서 결과로 한 번 더 확인되기 때문이다.
- F5 이후 F3으로 계속 이어지는 반복 영업은 구조상 막지 않지만, 첫 플레이 완료 판정에는 넣지 않는다.

## 3. 범위

### 넣는 것

| 분류 | 첫 플레이 범위 | 근거 |
| --- | --- | --- |
| 층 | 1층(시작) · 2층(성공 이상 2번이면 열림) | 첫 검증은 1~2층 (최신 결정) |
| 위험 축 | 여섯 축 판정은 모두 동작. 튜토리얼 안내는 독·체력 두 축만 | tutorial-spec 0장 |
| 손님 | 1일차 안내 손님 3명(고정 데이터) + 2일차 일반 생성 손님 | 17장 ③ |
| 종족·직업 | 💡 1~2층에 등장하는 조합만. 목록은 2번 작업에서 정함 | 2번 작업과 연결 |
| 컨디션 | 피곤(체력 +1). 1일차 안내 손님은 피곤하지 않음 | tutorial-spec 3·5장 |
| 개인 취약점 | 2일차부터. 1일차 3명에게는 없음 | 17장 ⑤ |
| 오늘의 이변 | 2일차부터 동작(60%, 한 층의 한 축 +1) | 노션 5장 |
| 좌석 | 시작 3석. 고정 자리 효과는 판정에 연결하되 튜토리얼 첫 손님은 효과 없는 기본석 | 최신 결정 · tutorial-spec T04 |
| 조리 | 직접 투입 → 확정 → 6초 자동 조리, 화구 2개 | 최신 결정 |
| 재료 | 기본 재료(밀가루·감자·고기) 무한·무료, 시작 양념 마늘 2·소금 2, 1~2층 전리품 재료 | tutorial-spec 8장 |
| 레시피 | 기본 재료 레시피 + 1~2층 재료로 열리는 레시피만 | 22개 전체는 확장 |
| 시간 정책 | 17장 ④ 표 그대로 (대화·수첩·재료 선택 중 영업 정지·조리 진행) | 17장 ④ |
| 경제 | 금화 획득, 양념 구매 | 노션 4·8장 |
| 귀환 판정 | 대성공 · 성공 · 간신히 · 부상, 전리품 3·2·1·0, 부상 이틀 결석 | 노션 5·9장 |
| 수첩 | 손님 기록, 확인한 개인 취약점 기록 | 17장 ⑤ |
| 독백 | 보고별 짧은 독백 + 첫 양피지 편린 1장(카엘 기준) | 17장 ③ |
| 저장 | 준비 완료 · 마감 · 귀환 결과 확정 자동 저장. 영업 중 종료는 영업 시작으로 복귀 | 저장 가안 |

## 5. 완료 확인표

아래 항목이 모두 확인되면 첫 플레이 범위를 "완료"로 본다. 구현 후 확인할 기준이며, 지금 통과했다는 뜻이 아니다.
튜토리얼 단계별 세부 사례는 tutorial-spec 9장을 그대로 쓴다.

### 성공 흐름

| # | 확인 상황 | 기대 결과 |
| --- | --- | --- |
| S1 | Title → 새 게임 | 1일차 튜토리얼 조합이 열리고 T00 안내가 나온다 |
| S2 | 첫 손님(인간 마법사)에게 구운 빵 + 마늘 | 독 1·체력 1을 막아 부족 합 0, 다음 아침 대성공 |
| S3 | 둘째 손님 조리 중 셋째 손님 응대 | 조리는 계속 진행되고, 응대 화면을 닫으면 접시가 ready일 수 있다 |
| S4 | 1일차 마감 | 매출·소비 양념·내려간 손님이 표시되고 저장된다 |
| S5 | 2일차 아침 보고 | 세 손님의 결과·대비 내역·전리품·수첩이 한 번씩 처리되고 첫 양피지 편린이 나온다 |
| S6 | 보고에서 얻은 재료 | 준비 화면에서 새 재료와 새로 열린 레시피를 볼 수 있다 |
| S7 | 1층 성공 이상 2번 | 2층만 열린다 |
| S8 | 2일차 영업 | 안내 없이 손님을 받고, 첫 손님의 개인 취약점 소개가 한 번 나온다 |
| S9 | 2일차 마감 → 3일차 아침 보고 | 2일차 결과가 1일차와 섞이지 않고 표시된다 |
| S10 | 저장 후 Title → 이어하기 | 마지막 저장 지점에서 금화·재고·레시피·열린 층·수첩이 그대로 돌아온다 |

### 예외

| # | 확인 상황 | 기대 결과 |
| --- | --- | --- |
| E1 | 맞는 요리가 없어 손님을 돌려보냄 | 던전에 가지 않고, 다음 아침 보고·전리품 없음 |
| E2 | 틀린 요리로 부상 | 보고에서 원인(어떤 위험이 얼마나 부족했는지)을 보여 주고, 그 손님은 이틀 오지 않는다. 게임은 계속된다 |
| E3 | 금화·양념이 0 | 기본 재료 요리로 영업을 계속할 수 있다 |
| E4 | 영업 중 게임 종료 후 이어하기 | 그날 영업 시작 지점으로 돌아오고 재고·금화가 이중 처리되지 않는다 |
| E5 | 귀환 보고 확정 후 종료·이어하기 | 전리품·호감·층 개방이 다시 적용되지 않는다 |
| E6 | 양피지 독백 생략 | 튜토리얼 완료와 보상이 유지된다 |
| E7 | 조리 확정 연타, 같은 접시 재서빙, 다른 손님에게 전달 | 재고 차감·조리·매출·탐험이 한 번만 처리되고 잘못된 전달은 막힌다 |

### 플레이 테스트로 확인할 것 (6번 작업)

- 테스트 참가자가 자기가 고른 음식의 이유를 말할 수 있다.
- 아침 보고를 보고 다음 영업에서 바꿀 점을 말할 수 있다.
- 튜토리얼 길이 💡 5~8분, 첫 플레이 전체 길이는 측정해서 기록한다.
