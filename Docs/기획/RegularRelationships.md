# 단골 호감·사연 — 웹 구현 명세

작성자: 송예찬 · 2026.10.26

## 0 기획 의도

V0.3 원고 3-3·4-6·4-8과 기존 「층계참 식당.html」의 단골 6명·사연 18개를 웹 시제품에 연결한다. 아래 수치는 기존 명세에서도 💡 가안이다. 주인공의 5층 구조 사건은 현재 StoryBTriggers 명세를 유지하며, 단골 사연만으로 생존·위치·엔딩을 확정하지 않는다.

## 1 플레이어 규칙

손님의 위험과 입맛을 함께 살피면 관계가 깊어진다. 다시 돌아온 단골은 자기 이야기를 들려주고, 약속한 재료나 작은 물건을 식당에 남긴다.

## 2 시스템 규칙

| 항목 | 적용 규칙 |
| --- | --- |
| 대상 | 보리·루·쥐·아멜·곡괭이·솔, 고정 단골 ID. 기존 무작위 과객의 이름·ID·취향은 유지한다. 과객의 단골 전환 조건은 🔴 미정으로 자동 전환하지 않는다. |
| 호감 범위 💡 | 0~12. 원형 코드의 상한 누락보다 기획서의 명시 범위를 따른다. |
| 귀환 변화 💡 | 대성공 +2 / 성공 +1 / 간신히·부상 0, 맛 3 이상 +1 / 맛 0 −1을 합산해 다음 아침 한 번 적용한다. 부상도 맛 증감은 기존 공식대로 적용한다. |
| 돌려보냄 💡 | 즉시 −1, 하한 0. 던전 결과·경험치·재료 없음. 같은 방문에 중복 적용 금지. |
| 사연 💡 | 호감 3·7·12에 도달하면 순서대로 해금한다. 호감이 내려가도 이미 얻은 사연·물건은 유지한다. 귀환 보고에서 읽고 수첩에서 다시 읽는다. 자동 팝업 없이 주인공 장면과 충돌을 피한다. |
| 약속 💡 | 입장 시 호감 5 이상이면 70% 확률로 목적지 층의 일반 재료 하나를 약속한다. 성공·대성공 귀환 시 해당 재료 +2. 약속은 방문에 저장해 자리 변경·재접속 시 다시 뽑지 않는다. |
| 추가 단서 💡 | 입장 시 호감 7 이상이면 양수 위험 중 서로 다른 큰 축 두 개를 말한다. 양수 축이 하나면 한 개만 말한다. |
| 최대 호감 보너스 💡 | 출발 시 호감 12이고 부상 없이 귀환하면 전리품 +1. 이번 귀환으로 처음 12가 되었다면 다음 출발부터 적용한다. 맛 보너스·약속 재료와 별도로 합산한다. |
| 레벨 💡 | 기본 1, 성공 이상 귀환 경험치 +1. 기존 원형의 `ceil(레벨/2)` 경험치로 1레벨 상승, 최대 6. 일반 영업에서는 해금 층과 레벨+1 중 작은 값까지 탐험하며 최고 가능 층 가중치 3. 5층 조사 시험은 기존의 강제 5층을 유지한다. |
| 등장 💡 | 새 일반 영업 첫날 보리·아멜·쥐. V0.4에서는 열린 자리 수만큼 3~6명을 동시에 받고 단골 2명을 우선하며 나머지를 과객으로 채운다. 방문 횟수가 적은 단골부터 순환한다. 부상 휴식·현재 외출자는 제외한다. 정확한 출현 비중·순환 정책은 🔴 미정이다. |
| 기록·정산 | 보고 ID로 호감·사연·경험치·보상을 한 번만 적용하고 저장한다. 이전 저장의 정산 완료 보고는 소급 계산하지 않는다. 이전 저장의 진행 중 영업은 보존하고 다음 영업부터 단골이 합류한다. |

## 3 데이터

| 기획 명칭 | 변수명 | 타입 | 초기값 | 비고 |

`src/define/regulars.json`에 원형 사연과 고정 취향을 보존한다. 종족은 V0.3 제안을 따른다. 솔의 7단계 대사에 있던 직접 사냥 표현은 현재 타이쿤 방향에 맞춘 💡 초안으로 교체한다. 🔴 최종 대사·고유 모델·성우·물건 외형·물건별 효과는 미정이다.

## 4 UI·피드백

- 손님·조리 화면: 단골 구분, 호감과 다음 사연, 이미 아는 취향, 약속 재료, 추가 위험 단서.
- 귀환 보고: 결과/맛에 따른 호감 변화 내역, 해금 사연, 실제 전리품, 약속 성공 여부, 레벨 상승. 수치와 대사에 💡 표시.
- 수첩: 단골 6명의 관계·만남 여부·해금 사연·다음 조건·남긴 물건. 과객 기록은 그대로 유지.
- 3D 식당: 사연 속 문장·스크롤·열쇠·구급함·기도문·광석·화살촉·지도를 작은 진열 선반에 표시한다. 💡 임시 형상. 화살촉은 장식이다. 사냥 기능이나 구급함 자동 회복 효과를 추가하지 않는다.
- 솔의 지도: 💡 다음 미개방 층의 기본 위험 한 축을 수첩에 공개한다. 미개방 층이 없으면 열린 층의 미기록 축을 찾고, 모두 알면 지도 장식만 남긴다. 5층 사건의 위치 단서로 취급하지 않는다.
- 💡 단골 사연 시험: 별도 저장 슬롯. 보리 2·아멜 6·솔 11에서 시작하고 이전 단계 사연은 시험용으로 기록한다. 풍부한 재료·화덕을 제공하되 요리·서빙·다음 아침 정산은 실제 게임 경로를 거친다. 일반 저장은 유지한다.
