### 스토리 B안 세부 설정 (정하지 않기로 한 범위 포함)

- 기간: 사고부터 게임 시작까지 수주 정도. 정확한 경과 기간은 정하지 않으며 개발 기간·플레이 제한 일수와 관계없다.
- 재료: 물·현지 균류·뿌리 식물과 취사 도구로 생활을 유지하는 안. 채집량 같은 세부값은 정하지 않는다.
- 지형: 연결부·고정점·안쪽 곁굴·바깥 경사면·새 연락 틈·정비로·우회 접근로. 컷씬(시네머신)이나 일러스트용 배경 설정이며 배치도는 만들지 않는다.
- 주인공은 카엘, 옛 파티는 카엘·모라·시에 총 3명이다. 엔딩 이후는 함께 귀환한 뒤 영업 재개를 따른다.
- 사용자 승인을 팀 전원 합의나 구현 완료로 표시하지 않는다.
