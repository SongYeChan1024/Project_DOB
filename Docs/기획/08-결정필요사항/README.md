## 스토리 B안 세부 결정 항목 🔴

기간: 사고부터 게임 시작까지 수주 정도.<br>
정확한 경과 기간은 정하지 않으며 개발 기간·플레이 제한 일수와 관계없다.

재료: 물·현지 균류·뿌리 식물과 취사 도구로 생활을 유지하는 안.<br>
채집량 같은 세부값은 정하지 않는다.

지형: 연결부·고정점·안쪽 곁굴·바깥 경사면·새 연락 틈·정비로·우회 접근로.<br>
컷씬(시네머신)이나 일러스트용 배경 설정이며 배치도는 만들지 않는다.

주인공은 카엘, 옛 파티는 카엘·모라·시에 총 3명이다.<br>
🟡 동료별 상태·질문과 답장·자기 처방 위험·도시락·장비·외부 협조·세부 저장 경계는 검토 대기다.<br>
엔딩 이후는 함께 귀환한 뒤 영업 재개를 따른다.<br>
사용자 승인을 팀 전원 합의나 구현 완료로 표시하지 않는다.
