# 3. 세계관과 스토리

[← 메인 기획서](../메인기획서.md)

던전 층계참의 작은 식당, 주인 카엘, 무작위로 찾아오는 다섯 종족의 손님, 1~5층 던전이 무대다.
옛 파티의 사고와 구조 이야기는 **데모 완성 후 남은 시간에 구현하는 후속 범위**이고, 첫 본영업 루프는 서사 없이 돌아가야 한다.

| 알고 싶은 것 | 문서 | 지금 제작에 쓰나 |
| --- | --- | --- |
| 식당은 어디에 있고 주인 카엘은 누구인가? 플레이어는 하루 동안 무엇을 하나? | [식당과 주인공 카엘](01-식당과주인공카엘.md) | 예 |
| 손님은 어떻게 생성되고, 종족·개인 취약점·단골은 어떻게 정하나? | [손님과 종족](02-손님과종족.md) | 예 (사연 재생은 후속) |
| 손님 이름은 어떻게 뽑고, 재방문·단골 전환 뒤에도 어떻게 유지하나? | [손님 이름과 재방문](손님이름과재방문.md) | 예 |
| 층마다 어떤 위험과 재료가 있나? | [던전 층과 재료](03-던전층과재료.md) | 예 (1층부터) |
| 카엘은 왜 혼자 돌아왔고, 동료들은 어떻게 살아남았나? | [옛 파티와 구조 이야기](04-옛파티와구조이야기.md) | 후속 |
| 그 이야기는 어떤 귀환 보고와 단서로 열리나? | [동료 구조 사건과 조건](동료구조사건과조건.md) | 후속 |

| 동료를 구한 뒤 식당은 어떻게 다시 여나? | [스토리 엔딩 이후 운영안](스토리엔딩이후운영안.md) | 후속 |

데모 엔딩과 스토리 엔딩은 다르다. 데모 엔딩은 [성장과 데모 엔딩](../04-핵심플레이/09-성장과데모엔딩.md), 스토리를 붙이는 조건은 [후속 스토리 조건](../04-핵심플레이/10-후속스토리조건.md)을 따른다.
