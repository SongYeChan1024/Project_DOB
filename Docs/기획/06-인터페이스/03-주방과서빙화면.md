# 주방과 서빙 화면

[← 6. 인터페이스](README.md) · [메인 기획서](../메인기획서.md)

규칙은 [주방과 서빙](../04-핵심플레이/06-주방과서빙.md)을 따른다. 이 문서는 주방 화면 배치와 조작, 완성 접시를 손님에게 전하기까지의 화면을 정한다.

## 주방 화면 배치

| 왼쪽 도구 자리 | 화면 가운데 | 오른쪽 도구 자리 |
| --- | --- | --- |
| 조리에 쓸 요리도구를 놓는다. | 현재 쓰는 조리도구를 가장 크게 보여 준다. 안에 담긴 재료·양념과 수량을 바로 읽을 수 있다. | 왼쪽과 같은 방식으로 도구를 집어 쓰고 제자리에 돌려놓는다. |

한 화면에서 현재 손님과 발견한 단서, 가운데 조리도구, 좌우 요리도구를 함께 본다. 화면 위에는 손님의 위험 칸, 아래에는 요리 효과 칸을 나란히 두어 비교한다.

💡 마우스 조작 예시: 좌우에서 필요한 도구를 골라 가운데로 옮기고, 재료를 골라 중앙 조리도구에 넣는다. 잘못 넣었으면 조리 시작 전에 내용물을 눌러 하나씩 꺼낸다. 마늘을 넣으면 해독 1이 보이고 빼면 그 효과가 사라진다. 좌우에 둘 도구의 종류와 순서는 레시피별로 시연하며 정한다.

## 확정에서 서빙까지

| 단계 | 화면에서 보이는 것 | 처리 기준 |
| --- | --- | --- |
| 재료 투입 | 내용물과 예상 맛·효과가 넣고 뺄 때마다 바로 바뀐다. | 기본 재료는 무제한이다. |
| 확정 | 양념 재고가 한 번 줄어든다. | 확정 순간 레시피·주문·화구·재고를 다시 검사하고, 모두 통과했을 때만 한정 재고를 한 번 차감한다. 중복 확정을 막는다. |
| 6초 자동 조리 | 주방을 떠나도 조리가 진행된다. | 이동·다른 업무가 가능하다. 💡 시작 화구 2개. 일시 정지 메뉴에서는 조리도 멈춘다. |
| 완성·픽업 | 완성 접시에 실제 주문자의 이름과 ‘완성’을 표시한다. | E로 집는다. 접시에 주문·손님 식별자를 연결해 중복 픽업과 잘못된 서빙을 막는다. 수첩이나 대사를 읽는 중이면 읽던 화면을 유지한다. |
| 서빙 | 주문한 손님에게 접시를 전달한다. | 다른 손님에게는 전달되지 않고 접시가 유지된다. 같은 주문을 두 번 완료하지 않는다. 서빙 때 금화를 한 번 지급하고 식후 반응으로 이어진다([식후 반응과 귀환 보고 화면](04-식후반응과귀환보고화면.md)). |

🔴 조리 도구 수·레시피 연결·동시 조리 규칙(냄비·프라이팬·오븐을 레시피와 연결하는 안)은 아직 정하지 않았다.
🟡 조리 중 손님이 떠났을 때 그 주문에 배정한 접시를 어떻게 처리할지 정해야 한다.
