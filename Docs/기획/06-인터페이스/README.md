## 6-1. 인터페이스 원칙

- 일러스트·대사·알려진 위험·요리 효과 비교·귀환 원인은 첫 플레이 루프에서 읽을 수 있어야 한다. 3D 이동·상호작용과 함께 검증하고 상세 장식·추가 연출은 이후 보완한다.

- 그림 4~7은 기존 개발 참고도로 보존한다.<br>
현재 응대는 E 전환과 2D 초상·단서 레이어, 자리는 고정 소품·연결 좌석을 따른다.<br>
그림과 최신 규칙이 다르면 본문과 2026-10-30 변경 기록을 기준으로 한다.<br>
번호·화살표는 설명용이며 캐릭터 후보·카메라 수치는 미확정이다.

- 여섯 위험 축과 효과의 색 규칙은 후순위 UI에서도 일관되게 적용한다. 🔴 UI 색감·글꼴·아이콘·말투는 팀 논의 후 확정한다.

- 공식은 숨기고, 무엇이 무엇을 막는지는 칩과 칸으로 보여 준다.

- 요리를 고르는 순간 완성될 효과를 미리 보여 준다.<br>
위험은 수첩에 기록된 만큼만 보인다.

- 결과는 반드시 원인과 함께 보여 준다.<br>
"부상"만이 아니라 "열 2칸 모자랐다"로.

- 대화·수첩·재료 선택 중에는 손님 입장·이동·기다린 시간을 멈추고, 6초 자동 조리는 계속 진행한다.<br>
일시 정지 메뉴·아침 보고·회상 중에는 조리도 멈춘다.

## 6-2. 화면 순서

제목 → 아침 귀환 보고 → 준비 [시장·레시피·수첩·가게] → 영업 [응대·주방·수첩] → 마감 → 다음 아침으로 진행한다.<br>
귀환 보고 정산 뒤 안전한 시점에 짧은 독백·양피지 기억 편린을 연결한다.<br>
생존·위치·구조 준비·자기 처방 검증 뒤 계단 출발과 귀환 후 영업 재개로 이어진다.<br>
게임 오버 화면 분기는 추가하지 않는다.

| 6 | 읽기 화면과 조리의 시간 정책 | 대화·수첩·재료 선택 중에는 손님 입장·이동·기다린 시간을 멈추고, 6초 자동 조리는 계속 진행한다.<br>일시 정지 메뉴·아침 보고·회상 중에는 조리도 멈춘다. |

그림 6. 자동 조리·서빙 제작 참고 — 그림 번호는 아래 표와 대응한다.<br>
재료·도구 구성은 예시이며 UI는 후순위다.

| 번호 | 3D 구현 요소 | 처리와 확인 기준 |

| 1 | 재료 투입 | 간단한 직접 재료 투입·조미료 선택 뒤 확정한다.<br>확정 순간 레시피·주문·화구·재고를 재검사하고 검사 전체 성공 때 한정 재고를 한 번 차감한다.<br>중복 확정을 막고 기본 재료는 무제한으로 처리한다. |

| 3 | 자동 조리 | 확정 후 6초 자동 조리하며 이동·다른 업무가 가능하다. 💡 시작 화구 2개.<br>대화·수첩·재료 선택 중에는 손님 입장·이동·기다린 시간을 멈추고, 6초 자동 조리는 계속 진행한다.<br>일시 정지 메뉴·아침 보고·회상 중에는 조리도 멈춘다. |
| 4 | 완성·픽업 | 완성된 접시를 픽업 위치에 표시한다.<br>접시에 주문·손님 식별자를 연결해 중복 픽업과 잘못된 서빙을 검사 |
| 5 | 손님에게 서빙 | 해당 손님에게 접시를 전달하면 맛 반응·금화 지급·출발 처리를 이어 간다.<br>같은 주문을 두 번 완료하지 않도록 처리 |

## 6-5. 귀환·결과 반영 제작 참고

[그림 — 원본 문서에서 보기](https://docs.google.com/document/d/1nFDNT7zw3tflOq4N4xJNqzioT0eQcbbVXVVCzUswXOE)

그림 7. 귀환·결과 반영 제작 참고 — 귀환(1) → 보고(2)·결과별 외형(3) → 전리품(4) → 기록(5) → 휴식·재방문(6).<br>
번호와 흐름도는 개발 설명용이다.

귀환 장면에서 손님 한 명씩 결과를 확인한다.<br>
결과 등급, 한마디, 부족했던 위험, 전리품, 새 레시피, 수첩 기록, 호감 변화를 처리한다.<br>
화면 카드와 건너뛰기 버튼 등 UI 표현은 후순위로 둔다.

구현 순서: 귀환 대상 확인 → 이미 정해진 탐험 결과 읽기 → 결과별 외형 적용 → 전리품·호감·기록 갱신 → 휴식·재방문 상태 반영. 🔴 저장 시점과 재진입 복구 규칙 확정.<br>
동일 귀환 건의 보상·기록이 중복 반영되지 않는지 확인한다.

## 6-6. 게임 조작 (3D 버전)

| 입력 | 동작 |
| --- | --- |
| W A S D | 이동 |
| E | 가까운 대상과 상호작용 (말 걸기, 자리 안내, 카운터 열기, 접시 들기 · 내기) |
| 마우스 | 대화 · 주방 · 보고 · 준비 화면 선택 |
| Tab | 수첩 열기 |
| Esc | 일시 정지 메뉴: 이어하기 · 저장 · 불러오기 · 환경설정 · 끝내기.<br>이어하기는 현재 세션을 재개하고 최근 자동저장의 일차와 날짜·시각을 표시한다 |
