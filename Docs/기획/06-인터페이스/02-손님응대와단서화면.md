# 손님 응대와 단서 화면

[← 6. 인터페이스](README.md) · [메인 기획서](../메인기획서.md)

규칙은 [손님 응대와 처방](../04-핵심플레이/01-손님응대와처방.md)과 [단서 추리와 수첩](../04-핵심플레이/04-단서추리와수첩.md)을 따른다. 이 문서는 그 규칙이 화면에서 어떻게 보이는지 정한다.

## 맞이에서 수첩 기록까지

| 장면과 시작 신호 | 플레이어가 보는 것 | 조작과 장면이 끝나는 조건 |
| --- | --- | --- |
| 손님 입장 | 무작위로 정해진 손님이 입구에 서고 실제 이름과 외형이 보인다. 종족은 입구에서부터 외형으로 읽힌다. | WASD로 다가가 ‘E 맞이하기’를 누른다. 같은 손님을 다시 응대하면 이름과 모습이 이어진다. |
| 응대 화면 | 쿼터뷰에서 1인칭 응대 구도로 바뀌고, 그 손님의 2D 초상과 평문 대사를 함께 둔다. 발견 전에는 마우스를 올려도 단서가 다른 글자와 똑같이 보인다. | 표현을 직접 찾아 클릭한다. |
| 단서 발견 | 클릭한 표현에 밑줄이 생기고 수첩이 펼쳐진다. 찾은 말과 위험 축이 기록된다. | 수첩을 덮으면 읽던 대사로 돌아온다. 응대 창을 다시 열어도 같은 대사와 발견 기록이 나온다. |
| 응대 종료 | 쿼터뷰로 돌아오면 손님이 플레이어를 따라온다. | 빈자리에 E로 안내한다. 착석하면 그 손님의 이름으로 주문이 열린다. 맞는 요리가 없으면 돌려보낼 수도 있다(방문 호감 −4, [호감과 입소문](../04-핵심플레이/08-호감과입소문.md)). |

## 단서 클릭 예시 — 같은 원인은 한 칸

수첩 칸은 **이번 방문에서 확인한 위험 원인별로 한 번만** 오르내린다. 표현마다 밑줄은 모두 남는다.
아래는 1층 슬라임 숲으로 가는 수인 사제의 예시다. 층의 독 +1, 수인의 예민한 코 +1, 사제의 가호 −1이므로 실제 독은 1이다. 실제 위험은 플레이어가 몇 개를 찾았는지에 따라 바뀌지 않는다.

| 이번 방문에서 발견한 것 | 화면에 남는 표시 | 수첩의 독 |
| --- | --- | --- |
| 아직 단서를 찾기 전 | 평문 대사 | 미확인 · 점선 빈 줄 |
| ‘슬라임 점액’ | 첫 표현에 밑줄 | 1칸 |
| ‘슬라임 점액’을 다시 클릭 | 기존 밑줄과 기록을 다시 확인 | 1칸 |
| 같은 문장의 ‘따끔’ | 두 표현 모두 밑줄. 둘 다 같은 층의 점액이 원인이다. | 1칸 유지 |
| 코를 감싸는 몸짓 | 수인의 독 약점 관찰 표시 | 2칸 |
| 목에 건 성표 | 사제의 독 보정 관찰 표시 | 1칸 |

보정을 확인해 합이 0이 된 축에는 축 이름과 빈 칸을 표시한다. 단서 흐름은 [손님 단서 흐름도](../04-핵심플레이/흐름도/02-손님단서.png)에 있다.

> **이전 방식(이력)** — 2026-11-24 첫 영업 연출안은 찾은 표현 수만큼 칸을 세어 ‘슬라임 점액’ + ‘따끔’을 독 2칸으로 보여 줬다. 현재는 위의 원인별 방식이 기준이며([구현 기능과 총괄 Manager 구성안 F11](../../개발/FeatureManagerMap.md)), 표현 수 방식은 쓰지 않는다.

그림 번호는 아래 표와 대응한다. 외형·거리·카메라 구도는 미확정이며, 그림과 본문이 다르면 본문이 기준이다.

| 번호 | 구현 요소 | 처리와 확인 기준 |
| --- | --- | --- |
| 1 | 상호작용 위치 | E로 맞이하면 쿼터뷰에서 1인칭 응대 구도로 전환한다. 접근 거리·앵커는 그레이박스에서 검증한다. |
| 2 | 종족 외형 | 운영용 3D 실루엣과 응대용 종족·직업 2D 기본 초상을 구분한다. 고품질 3D 얼굴 확대·회전을 전제로 하지 않는다. |
| 3 | 직업 장비 | 직업 데이터에 맞는 장비를 표시한다. 장비 외형과 직업 보정이 서로 맞는지 확인한다. |
| 4 | 컨디션 단서 | 응대용 2D 초상에 컨디션·개인 취약점·단서 레이어와 대사·아이콘을 연결한다. 피곤함·개인 취약점·과거 흔적·목적지 정보를 구분하고, 위험은 저장된 데이터에서 계산한다. |
| 5 | 관찰 카메라 | 대화 시작 시 관찰 구도로 바꾸고 끝나면 원래 구도로 돌아온다. 🔴 거리·각도·전환 방식 |
| 6 | 읽기 화면과 조리 | 대화·수첩·재료 선택 중에도 손님 입장·이동·기다린 시간과 6초 자동 조리가 흐른다. Esc 일시 정지 메뉴에서만 멈춘다(FeatureManagerMap F2, [화면 순서와 조작](01-화면순서와조작.md#시간이-멈추는-화면)). |

## 한 초상에 여러 단서가 겹칠 때 (💡 다음 시연 장면)

손님의 타고난 특징, 지난 탐험의 흔적, 오늘 대비할 증상이 한 초상에 겹칠 수 있다.
예: 손님이 한 번 기침하고 “요즘 목이 칼칼해”라고 말할 때 목 주변 표정에 시선이 가게 한다. 플레이어가 그 표현을 찾아 이 손님의 수첩에서 다시 확인할 수 있는지 본다. 취약점 대사는 [손님 대사와 단서 원고](../04-핵심플레이/손님대사와단서원고.md)에 있다.
