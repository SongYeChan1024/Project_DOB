> 이 문서의 ‘첫날’은 **0일차 연습 영업**이다. 게임 안에서는 1일차 본영업보다 먼저 오지만, 제작은 본영업 루프를 완성한 뒤에 붙인다([구현 기능과 총괄 Manager 구성안 F14](../../개발/FeatureManagerMap.md)).
> 응대·주방·식후 반응·귀환 보고의 공통 화면은 [손님 응대와 단서 화면](02-손님응대와단서화면.md), [주방과 서빙 화면](03-주방과서빙화면.md), [식후 반응과 귀환 보고 화면](04-식후반응과귀환보고화면.md)으로 옮겼다. 이 문서에는 연습 영업에만 있는 진행 방식과 시연 기준을 남긴다.

새 게임의 첫 손님부터 무작위로 등장한다. 플레이어는 그 손님의 말과 외형에서 단서를 찾고, 주방에서 어울리는 한 끼를 준비한다. 퇴장할 때는 음식이 입에 맞았는지 짐작하고, 다음 아침 같은 손님이 돌아오면 그 식사가 탐험에 어떤 도움이 됐는지 듣는다.
연습 손님 세 명(안내 1명 + 병행 2명)과 다음 아침 보고, 재영업 시작까지 다룬다. 단계와 판정은 [첫 영업 플레이 검수](../04-핵심플레이/첫영업플레이검수.md), [시험 손님과 판정 데이터](../05-데이터/시험손님과판정데이터.md), [현재 결정과 검토 사항](../08-결정필요사항/현재결정과검토사항.md)을 따른다.

## 💡 연습 진행 방식 — 점점 놓아 주기 + 카엘 메모

송예찬 결정 2026-11-24(팀 합의 전). 원칙은 **한 번 보여 주고 → 한 번 같이 하고 → 한 번 혼자 해 본다**이다. 연습 손님 세 명이 각각 한 단계씩 맡는다.

| 목소리 | 맡는 내용 | 형식 |
| --- | --- | --- |
| 안내 UI | 조작: 어디로 가서 무엇을 누르는지 | 화면 하단 한 줄(존댓말) + 대상 외곽선 강조 |
| 카엘 메모 | 의미: 왜 그렇게 하는지 | 수첩에 손글씨로 적히는 짧은 반말 메모. 나중에 수첩에서 다시 읽는다. 과거사는 꺼내지 않는다 |
| 손님 | 단서와 결과 | 평문 대사의 단서 표현, 각오 한마디, 다음 아침 보고 |

| 구간 | 잠금 | 진행과 연출 | 카엘 메모 예시 |
| --- | --- | --- | --- |
| 가게 문 열기 | — | 외경 → 카엘이 간판 등을 켜는 짧은 컷 → 쿼터뷰. 💡 연습 영업은 기다린 시간과 떠남을 끄는 안(대기 점수 2 고정·이탈 끄기, 검토 중)이라 시간 압박이 없다. 본영업에는 적용하지 않는다. | — |
| 손님 1 · 보여 주기 | 단계 잠금 | 무작위로 뽑힌 첫 손님. 맞이 → 단서 클릭 → 관찰 → 자리 안내(효과 없음) → 주방 순서로만 진행한다. 조리 화면 위에 손님 위험 칸, 아래에 요리 효과 칸을 나란히 두고 맞는 칸이 찰 때마다 체크 표시를 한다. **찾아낸 위험 칸을 모두 채워야 확정할 수 있다.** 돌려보내기 버튼은 아직 보이지 않는다. | “같은 만큼 챙겨 주면 된다.” (손님 1 출발 뒤) |
| 손님 2 · 같이 하기 | 잠금 해제 | 두 손님이 함께 들어온다. 확정 잠금이 풀려 틀린 요리도 낼 수 있다. 15초 동안 아무 행동이 없을 때만 종족·직업 관찰 대상을 강조하고 카엘 메모를 띄운다. 돌려보내기 버튼이 이때부터 보인다. | “몸이 작으면 먼 길이 더 길다.” (종족이 위험을 늘리는 경우) |
| 손님 3 · 혼자 하기 | 잠금 해제 | 힌트 없이 진행한다. 직업이 위험을 줄이면 해당 칸이 지워지는 연출로 보여 준다. 필요한 양념이 모자라면 안내 대사로 한 번 알리고 막지는 않는다(첫 영업 플레이 검수 E1). | — |
| 마감 → 밤 | — | 마지막 방문이 끝나면 정산을 한 번 연다. 카엘이 방명록을 펼쳐 세 사람의 글을 읽고 등불이 꺼진다. | — |
| 다음 아침 | — | 실수했다면 보고가 두 번째 수업이다. 부족했던 줄이 깜빡이고 메모가 남는다. 연습 손님 중 실제로 던전에 간 손님만 보고한다. 양피지와 카엘 독백은 스토리 범위이므로 첫 루프 사운드 신호와 데모를 완성한 뒤 남은 시간에 붙인다. | “마늘이 하나 모자랐다. 내일은 넉넉히.” |

- 손님 1은 무작위 손님이므로 고정된 재료를 지시하지 않고 “찾아낸 위험 칸을 모두 채우기”로 잠금 조건을 일반화한다.
- 병행 연습에서는 조리 중 다른 손님과 대화하고, 접시의 주문자 이름을 보고 서빙한다.
- 🟡 노션 카드 01 E3는 연습 중 돌려보내기를 허용한다. 손님 1 구간에서만 버튼을 숨기는 해석이 맞는지 팀 확인이 필요하다.
- 🔴 T00~T13 원고를 이 구간에 맞게 다시 나누고, 안내 UI 문장과 카엘 메모 문장을 분리하는 작업은 [손님 대사와 단서 원고](../04-핵심플레이/손님대사와단서원고.md)에서 한다.
- 🔴 연습 수입·재고·호감·입소문 중 1일차로 넘길 항목과 최초 저장·보고 시점은 아직 정하지 않았다.

## 제작 인계와 플레이 확인

| 담당 | 첫 시연에서 확인할 장면과 완료 기준 |
| --- | --- |
| 송예찬 · 기획/PM | 첫 플레이어에게 조작을 대신 설명하지 않고 지켜본다. 주방에서 “왜 그 재료를 골랐나요?”, 아침에 “어제 한 선택 중 뭐가 도움이 됐나요?”라고 묻는다. 단서·재료·돌아온 결과를 연결하는지, 어느 장면에서 도움말이 필요했는지 기록한다. |
| 홍준우 · 화면/입력 | 클릭 뒤 밑줄·수첩 칸, 좌우 도구 선택과 중앙에서 넣기·빼기, 퇴장 표정과 방명록의 맛 반응이 같은지 확인한다. |
| 김언호 · 상태/판정 | 양념 선택·취소까지 재고 유지, 연속 확정·서빙에도 재고·금화 1회 처리, 마지막 글 완료 후 정산 1회, 보고 재진입 시 보상 1회를 확인한다. 조리 잔여 4초에 10초 대화한 뒤 해당 주문의 접시를 집을 수 있어야 한다. |
| 이기혁 · 아트/연출 | 서로 다른 외형의 손님으로 입장과 귀환을 시연한다. 무음에서도 같은 손님을 알아보는지, 이동 중 세 표정의 차이를 한눈에 읽을 수 있는지 확인한다. |

새 게임을 여러 번 열어 서로 다른 이름과 종족·직업 조합에서도 같은 조작을 끝까지 할 수 있는지 확인한다. 무작위 추첨에서는 같은 결과가 다시 나올 수 있다. 연습 영업 목표 5~8분을 재면서 단서를 찾는 데 걸린 시간, 도구에서 재료를 뺄 수 있었는지, 퇴장 표정을 어떻게 읽었는지 기록한다.
